basco.covariance.square_root

Stacking the whitened observation rows and the whitened a priori rows into one least-squares problem, for a solver.

"Square root" refers to working with the rows themselves (a square root of the information matrix H^T H) instead of forming H^T H, which would square the condition number.

SquareRootInformation

SquareRootInformation(data_rows: object, prior_rows: object, data_rhs: object, prior_rhs: object, residual: object, noise: object, blocks: tuple)

A complete least-squares problem: rows and right-hand sides, for fitting.

data_rows, data_rhs: whitened design matrix and whitened residuals (observed minus predicted). prior_rows, prior_rhs: whitened a priori rows and residuals. residual: the residuals before whitening. noise, blocks: the noise and the a priori information they came from.
