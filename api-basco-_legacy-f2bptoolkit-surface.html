basco._legacy.f2bptoolkit.surface

Legacy compatibility reference. Prefer current BASCO workflows; copied implementation details are not new development targets.

Polyhedral surface utilities for binary asteroid dynamics.

Provides closed-form polyhedral gravity (Werner & Scheeres 1997) plus mesh inside/outside and signed-distance tests for surface-process work:

  • :class:PolyhedronMesh — pre-computed face/edge data
  • :func:polyhedron_gravity — attractive gravitational accel., vectorised over field points with memory-capped chunking.
  • :func:load_aligned_polyhedron — load a PolyhedronShape whose vertices have been translated to the COM and rotated to principal axes (matching what GUBAS uses internally).
  • :func:mesh_inside — solid-angle inside/outside test.
  • :func:mesh_signed_distance — Euclidean signed distance to the nearest face (negative inside). Used as an event function for landing-trajectory collision detection.

All quantities are in SI (m, kg, s). polyhedron_gravity returns the attractive acceleration: at far field it reduces to −G·M·r̂ / r².

Verified on the KW4 secondary against the point-mass limit: 0.1 % at 5 km, 1 ppm at 50 km.

PolyhedronMesh

Import as basco._legacy.f2bptoolkit.surface.PolyhedronMesh

PolyhedronMesh(vertices: np.ndarray, faces: np.ndarray)

Pre-computed face/edge data for fast Werner-Scheeres gravity and inside/outside queries on a closed, uniform-density polyhedron.

Faces must be triangles wound CCW as viewed from outside the body (positive signed tetrahedral volume). load_aligned_polyhedron returns data with the correct orientation.

polyhedron_gravity(field_points: np.ndarray, mesh: PolyhedronMesh, density: float, G: float=_G_SI, chunk_size: int=64) -> np.ndarray

Werner-Scheeres (1997) attractive gravitational acceleration of a closed uniform-density polyhedron, evaluated at field_points.

Parameters

field_points : (K, 3) array_like Points in the same coordinate frame as mesh.vertices. mesh : PolyhedronMesh Pre-computed mesh data. density : float Bulk density, kg/m³. G : float Gravitational constant, m³ kg⁻¹ s⁻². Defaults to 6.674e-11. chunk_size : int Field-point chunk size used to cap peak memory consumption. Peak intermediate arrays are O(chunk_size × E_mesh × 3 × 8 bytes).

Returns

_min_sq_distance_to_triangles

_min_sq_distance_to_triangles(p: np.ndarray, v0: np.ndarray, v1: np.ndarray, v2: np.ndarray) -> float

Minimum squared distance from point p to any of the (F,) triangles defined by (v0, v1, v2). Vectorised over all faces.

Implements the classic point-in-triangle closest-point algorithm (Ericson, "Real-Time Collision Detection", §5.1.5) extended to handle the vertex / edge / interior cases simultaneously across all faces.
