basco.validation.particle_studies.gravity_comparison

Data-only comparison of receiving-field models for the same nominal particles.

A FieldStudy holds several runs of identical launches that differ only in the gravity each asteroid exerts on the particles. A FieldSurvey measures the static field error directly on shells around a mesh. Neither imports a renderer, and nothing here integrates dynamics, so saved results can be reloaded and redrawn. Differences use exactly matched saved epochs; nothing is interpolated.

FieldSurvey

FieldSurvey(body: str, enclosing_radius_m: float, keys: tuple, labels: tuple, radius_ratio: object, altitude_m: object, relative_error: object, face_altitude_m: float, face_error: object)

Static fractional acceleration error of each candidate field for one body.

keys and labels name the candidates, in the order of the last axis of relative_error and face_error. radius_ratio is r divided by the enclosing-sphere radius and altitude_m the height above the mesh of each sample. face_error holds the same fractional error at face_altitude_m directly above every mesh face, for surface maps. The reference and candidates share one mass distribution, so these errors measure truncation of the candidates alone, not the true asteroid interior.

field_survey

field_survey(body, mesh, reference, candidates, *, altitudes_m, samples=120, seed=1, face_altitude_m=1.0)

Compare candidate accelerations with a reference on mesh-offset shells.

candidates maps a key to (label, field). Sample points sit altitudes_m along the outward normals of area-weighted random faces, keeping only points that remain outside the mesh. Every field is evaluated in the mesh's body frame. No trajectory or finite difference is computed.

FieldStudy

FieldStudy(runs: tuple, names: tuple, reference: str, target: str, masses_kg: object, meshes: object, launch_speed_m_s: object, launch_direction: object, metadata: object, floor: str | None = None, body_names: object = None)

Runs of the same launches under different receiving-field models.

masses_kg and meshes are keyed by body, A and B; meshes holds the body-frame shapes used for events and display. launch_speed_m_s and launch_direction are per-particle values used to group results. reference names the run other runs are measured against. target is the launch body. floor optionally names a run with the reference's physics and tighter integration settings, whose difference from the reference shows what numerics alone produce. body_names labels A and B. metadata records every assumption that produced the runs.
