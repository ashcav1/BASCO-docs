basco.spacecraft.release

Body-fixed spacecraft release conditions and their exact local SI map.

Release is an initialization map, independent of propagation, observations, source uncertainty and covariance solvers. The release epoch belongs to the handoff adapter; this module describes geometry at a supplied binary state.

ReleaseEvaluation

Import as basco.spacecraft.ReleaseEvaluation

ReleaseEvaluation(state: SpacecraftState, state_jacobian: object, mass_jacobian: object, release_jacobian: object)

Inertial release state and exact local Jacobians, all immutable.

state_jacobian [6,30] differentiates native binary storage coordinates; mass_jacobian [6,2] differentiates primary/secondary masses in kg. release_jacobian [6,6] differentiates body-fixed position in m and its body-frame time derivative in m/s. Higher raw moments have no additional direct pathway at this instantaneous map; binary transport supplies their indirect effect on the retained state.

BodyFixedRelease

Import as basco.spacecraft.BodyFixedRelease

BodyFixedRelease(body: str, position: object, velocity: object)

COM-relative offset rho and its body-frame time derivative u on exactly primary or secondary. The inertial map is r=c+R rho, v=vc+Rdot rho+R u. Rotation rates use the coded binary equations at the retained state, without DCM projection or an off-manifold orthogonality substitution. This map does not assert contact with a surface.

Position and relative velocity resolved in one asteroid's body frame.

body is exactly "primary" or "secondary". position is the COM-relative offset rho [m]; velocity is its body-frame derivative u = d(rho)/dt [m/s], including the intended motion relative to that frame. Plain arrays use SI. Compatible Astropy quantities are converted here. A stationary surface-relative release has zero velocity; its inertial velocity still includes body translation and rotation. No contact/surface assertion is made by this purely kinematic map.

BodyFixedRelease.evaluate

evaluate(self, native_state, mass_A, mass_B)

Return the inertial six-state and analytic Jacobians with respect to all native30 binary coordinates, both masses and six release coordinates. Stored native lengths/velocities use km and km/s; release inputs/outputs use SI. Higher moments enter indirectly through the retained binary state map.

Map to inertial barycentric SI using the retained binary kinematics.

rS = c + R rho and vS = vc + Rdot rho + R u. Rdot is evaluated from the actual coded native/AD DCM equations, including off-manifold products; attitudes are never projected. Complete local Jacobians retain both mass-dependent barycenter translations and all spin, velocity and stored DCM pathways.
