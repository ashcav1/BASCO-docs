basco.spacecraft.uncertainty

Named source distributions and explicit independent spacecraft release errors.

This module supplies covariance inputs to the existing output-map machinery. It neither generates observations nor solves an estimation problem. A supplied singular covariance describes an exact finite distribution; an unobservable direction in an existing estimation result keeps that result's null policy.

SourceUncertainty

Import as basco.spacecraft.SourceUncertainty

SourceUncertainty(layout: CoordinateLayout, factor: object, source: str, reference_epoch_s: float, information_cutoff_s: float, diagnostics: dict, _delegate: object = field(repr=False), _appended_factor: object = field(repr=False), _appended_conventions: dict = field(repr=False))

Covariance-only input distribution. Use from_factor for declared physical factors, from_covariance for new supplied PSD matrices, and from_result for existing BASCO solves so their original factors and null-support policy remain intact. Independent inertial or body-fixed release errors can be appended explicitly. Supply a complete joint factor with a release descriptor when binary/release errors are correlated.

A declared physical error distribution, with an original source factor.

Construct with from_factor, from_covariance or from_result. factor has physical rows in layout order and dimensionless latent error columns, so P = factor @ factor.T. No characteristic scale is multiplied into it. The reference epoch names the source coordinates; the information cutoff names the information already included in them. Neither field adds observations or changes a covariance.

from_result retains the source result and delegates its numerical and null-support policy, including the cancellation-aware consider map. with_independent_spacecraft appends inertial initial errors, while with_independent_release appends body-fixed release errors at a separate declared epoch. Both assume zero cross covariance to the original source. For correlated release errors, supply a complete joint factor and layout to from_factor.

SourceUncertainty.with_independent_release

with_independent_release(self, release, covariance=None, *, factor=None, release_epoch_s, scales=None, source='independent body-fixed release uncertainty')

Append six body-fixed COM-offset/relative-velocity errors independent of the original source. The recorded release body, nominal geometry, units and release_epoch_s must agree with the initialization. Original reference/cutoff epochs, factors, consider cancellation and null policy remain intact. Input independence does not remove correlations induced by the uncertain body-to-inertial release map.

Append independent body-fixed release position and velocity errors.

release is a BodyFixedRelease. Its six coordinates are COM offset xyz in metres followed by body-relative velocity xyz in metres per second. Supply exactly one six-by-six covariance or six-row physical factor. release_epoch_s names these release coordinates; the original source reference epoch and information cutoff stay fixed.

Independence here refers to the supplied release errors and the original binary source. The release-to-inertial state map still creates cross covariance through the uncertain body position, attitude and spin. For correlated source/release errors, use from_factor instead.

SourceUncertainty.map_factor

map_factor(self, jacobian)

Map a physical Jacobian into original latent errors. Supplied sources use J@F; result-backed sources require their explicit map_factor capability. Independent release/inertial factors retain trailing latent columns. Full-source Jacobians still determine null availability; no factor reconstruction, new information or extra latent rank is introduced by mapping.

Map supported finite directions in the original latent column order.

jacobian is a finite two-dimensional map using every physical source column. Result-backed sources delegate to their original factor-mapping capability, retaining cancellation-aware consider algebra. Independent appended errors retain their own trailing latent columns.

This is a supported-subspace factor, not an availability test. A finite returned row does not imply finite covariance for an unobservable output; use derived_stable to apply the original result's null-support policy. Missing result capabilities fail rather than reconstructing dense factors.
