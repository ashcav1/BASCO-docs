basco.spacecraft.uncertainty

Named source distributions and independent spacecraft initial errors.

This module supplies covariance inputs to the existing output-map machinery. It neither generates observations nor solves an estimation problem. A supplied singular covariance describes an exact finite distribution; an unobservable direction in an existing estimation result keeps that result's null policy.

SourceUncertainty

Import as basco.spacecraft.SourceUncertainty

SourceUncertainty(layout: CoordinateLayout, factor: object, source: str, reference_epoch_s: float, information_cutoff_s: float, diagnostics: dict, _delegate: object = field(repr=False), _appended_factor: object = field(repr=False))

Covariance-only input distribution. Use from_factor for declared physical factors, from_covariance for new supplied PSD matrices, and from_result for existing BASCO solves so their original factors and null-support policy remain intact. Adding spacecraft uncertainty is explicitly independent unless the complete joint factor is supplied.

A declared physical error distribution, with an original source factor.

Construct with from_factor, from_covariance or from_result. factor has physical rows in layout order and dimensionless latent error columns, so P = factor @ factor.T. No characteristic scale is multiplied into it. The reference epoch names the source coordinates; the information cutoff names the information already included in them. Neither field adds observations or changes a covariance.

from_result retains the source result and delegates its numerical and null-support policy, including the cancellation-aware consider map. with_independent_spacecraft appends six SI initial-error coordinates with an explicit zero cross covariance to that source. For a correlated release, supply a complete joint factor and layout to from_factor.

SourceUncertainty.from_result

from_result(cls, result, *, reference_epoch_s, information_cutoff_s, source='BASCO covariance result')

Retain the existing covariance/consider result at its actual reference epoch and included-information cutoff. Relabeling an epoch does not advance nominal dynamics. A later-epoch Hera release needs the separately planned handoff adapter.

Retain an existing result's full factor, correlations and null policy.

CovarianceResult and ConsiderResult are accepted through their common factor/map capability. A missing original factor is an error; the dense covariance is never eigendecomposed as a substitute. Known source epochs must agree with the declared epochs.
