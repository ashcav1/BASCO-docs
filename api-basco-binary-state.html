basco.binary.state

The GUBAS state: how the binary's state is stored while it is propagated.

It is the layout of the GUBAS C++ code, kept so that its equations and partials are used unchanged: 30 numbers, with lengths in kilometres.

entries  name     meaning                                                      unit
0-2      R        position of the secondary relative to the primary,          km
                  components in the primary's frame (A)
3-5      V        inertial velocity of the secondary relative to the          km/s
                  primary, components in A
6-8      OMEGA_A  spin vector of the primary, components in A                 rad/s
9-11     OMEGA_B  spin vector of the secondary, components in A               rad/s
12-20    C_NA     rotation matrix from A to the inertial frame N, row by row
21-29    C_AB     rotation matrix from the secondary's frame B to A, row by row

Use the slices below instead of numbers: state[R], state[C_NA].reshape(3, 3). BinaryState in models.py is the same state in SI units, for input.

decode_gubas_states(states)

A few quantities of a state history (n, 30) in SI units, for reports and plots.

Returns the relative position in inertial axes [m], the separation [m] and the two spin rates [rad/s]. The states are used as stored; nothing is corrected or normalized.

dcm_orthogonality_error

dcm_orthogonality_error(states)

How far the two attitude matrices are from perfect rotations: the largest entry of |C^T C - I|, for one state or the largest over a state history.

A fixed-step integrator lets the matrices drift slowly; this number measures that drift.

gubas_inertia_integral_scale(inertia_integral_indices)

inertia_integral_indices are (body, l, m, n); the degree is l + m + n.

apply_state_deviation

Import as basco.covariance.apply_state_deviation

apply_state_deviation(gubas_state, physical_error)

Apply a finite physical SI/local-SO(3) error to a native30 state. This is an explicit estimation/retraction utility rather than a propagation-time correction.

The GUBAS state after adding a state deviation of 18 numbers in SI units.

0-5    change of the relative position [m] and velocity [m/s], components in A
6-11   change of the two spin vectors [rad/s], components in A
12-14  rotation vector theta_A [rad]: C_NA becomes exp([theta_A x]) C_NA
15-17  rotation vector theta_B [rad]: C_AB becomes exp([theta_B x]) C_AB

An attitude has three degrees of freedom, not nine, which is why a deviation has 18 numbers and the state 30. The attitude matrices are multiplied from the left and are not re-orthogonalized.
