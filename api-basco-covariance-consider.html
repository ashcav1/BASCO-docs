basco.covariance.consider

Consider covariance: the effect of parameters that are uncertain but not estimated.

Split the unknowns into estimated ones x and consider parameters c. The whitened equations (observations and a priori information) are

A dx + B dc = noise

Only x is estimated; c is held at its nominal value, although it is really uncertain with covariance C. An error dc in the consider parameters shifts the estimate by S dc, with the sensitivity matrix

S = -A^+ B                    (A^+ is the least-squares inverse of A)

so the covariance of the estimate is

P_x  = P + S C S^T            P = (A^T A)^-1, the covariance if c were known exactly
P_xc = S C                    the cross covariance with the consider parameters

The observations do not improve the knowledge of c: C stays as given. This is the batch consider covariance (as in Tapley, Schutz and Born), not a sequential filter.

The consider parameters and their covariance.

labels, units: the unknowns that are considered, by name, with their units. covariance: their covariance C. It may be singular, and zero variances are allowed. name, source: for the records.

The remaining fields are filled in: factor is a matrix L with L L^T = C, and normalization notes any rounding-level correction that made C exactly symmetric and positive semidefinite.

ConsiderParameters.from_priors

from_priors(cls, priors, layout, nominal, *, labels, name='consider', source='prior-derived external covariance', solver=None)

The consider covariance of some unknowns from a priori information about them.

priors are ordinary a priori objects (for example a Kaula rule); labels selects the unknowns to consider. The a priori information about them must involve no other unknown, must be centred on the nominal values and must determine all of them.

Use this to consider parameters "at their a priori uncertainty". Do not also pass the same a priori information to the estimator.

ConsiderResult.derived

derived(self, labels, values, units, jacobian, conventions=None)

The uncertainty of quantities q with partials jacobian = dq / d(all unknowns).

With J = [Jx, Jc] split like the unknowns, an error of q is Jx dx + Jc dc, and

cov(q) = Jx P Jx^T + (Jx S + Jc) C (Jx S + Jc)^T

The second term is evaluated in this form because Jx S and Jc often nearly cancel.

ConsiderResult.map_factor

map_factor(self, jacobian)

Return [Jx Fconditional, (Jx S + Jc) Lconsider] with the same latent columns as observable_subspace_factor. Combining fitted-response and direct consider dependence before applying the external factor preserves cancellation. The external distribution, estimated rank and conditional nullspace remain unchanged; a finite mapped row does not establish observability.

J F for a matrix of partials J: a factor of the covariance of the quantities J x.

Its columns are [Jx F_P, (Jx S + Jc) L], with F_P F_P^T = P and L L^T = C. Carrying this factor forward and squaring at the end keeps the near-cancellation between the fitted response Jx S and the direct effect Jc.

analyze_consider

Import as basco.covariance.analyze_consider

analyze_consider(whitened_rows, layout, consider, *, prior_rows=None, prior_descriptions=(), solver=None, parameters=None, diagnostics=None, rank_rtol=None)

The consider analysis of whitened rows whose columns cover all unknowns.

The columns are split into estimated ones (A) and considered ones (B). solver gives the covariance P of the estimated unknowns from A; the sensitivity S = -A^+ B is then computed with the same solver, so that both use the same treatment of undetermined directions.

The consider covariance C is never added as a priori information: it does not help the estimate. The noise of the equations and the error of the consider parameters are assumed independent.
