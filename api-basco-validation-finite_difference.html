validate_jacobian

Import as basco.validation.validate_jacobian

validate_jacobian(forward: ArrayFunction, jacobian: ArrayFunction, request: ProbeRequest, tolerances: Tolerances, *, name='jacobian', equation_id='unassigned', provider='manual_analytic') -> ValidationResult

User-invoked derivative comparison over explicit scale-aware finite-difference probes. This is separate from the ordinary covariance workflow; validation claims cover only the chain actually exercised by each check.

Compare scaled derivative actions using FD-only step selection.

forward accepts independent physical coordinates. A rotation/model adapter supplies its own retraction inside forward; this engine never perturbs DCM entries implicitly. No result is a certification of unrequested directions.
