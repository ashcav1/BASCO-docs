basco.spacecraft.field

Hou gravity of one extended body acting on a massless point particle.

The retained mutual potential is evaluated with the asteroid as body A and a unit monopole as body B. Its potential energy divided by that unit mass is the asteroid's specific potential. No spacecraft mass or inertia enters the binary equations. These homogeneous equations are evaluated directly in SI here; there is no implicit kilometre conversion or normalization by asteroid mass.

FieldEvaluation

FieldEvaluation(acceleration: object, position_jacobian: object, moment_jacobian: object)

One local asteroid field and its exact local derivatives, all in SI.

Attributes

HouBodyField

Import as basco.spacecraft.HouBodyField

HouBodyField(moments: object, order: int = dataclass_field(kw_only=True), G: float = dataclass_field(kw_only=True), backend: str = dataclass_field(default='ad', kw_only=True), _flat: object = dataclass_field(init=False, repr=False, compare=False), _native: object = dataclass_field(default=None, init=False, repr=False, compare=False))

Advanced local SI field adapter: the asteroid is the extended Hou body, the receiver is a unit monopole. Acceleration, position gradient and selected mass-weighted raw-moment derivatives are distinct from normalized physical parameter partials. The dynamics caller owns frame transforms, exterior bounds and the raw-to-physical chain rule.

Hou specific field of an extended asteroid for a point spacecraft.

Parameters

moments : mapping Body-frame mass-weighted SI moments {(l,m,n): T_lmn}, where T_lmn = integral xl ym z**n dm. T000 is the positive mass in kg; omitted slots are explicitly zero. The caller supplies a table through the selected order, not a mass-normalized moment or harmonic table. order : {2, 4, 6}, keyword-only Maximum Hou expansion degree. This is a single-body field; a unit receiving monopole makes total mutual order equal to asteroid degree. G : float, keyword-only Positive gravitational constant in m³/(kg s²). backend : {"ad", "native"}, keyword-only AD is the default and lazily requires basco[ad]. Native retains the hand-derived scalar-potential gradient and Hessian; no fallback occurs.

Positions and returned vectors use the asteroid's own body frame. The exterior expansion's convergence domain must be checked by the caller against the asteroid's enclosing radius; a finite value inside that sphere does not establish physical validity.

Examples

field = HouBodyField({(0, 0, 0): 5e11}, order=6, G=6.674e-11, ... backend="native") result = field.evaluate([1500., 0., 0.], slots=((0, 0, 0),)) result.acceleration.shape, result.moment_jacobian.shape ((3,), (3, 1))
