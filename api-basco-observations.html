PrimaryBarycentricPosition

Import as basco.PrimaryBarycentricPosition

PrimaryBarycentricPosition(sigma: object = 1.0, nuisance: object = None)

Predict the primary position relative to system center of mass: -M_B/(M_A+M_B) times inertial relative separation, plus optional bias. Includes direct mass-ratio derivatives as well as transported dynamical effects. sigma is in metres.

Primary position in the inertial binary barycenter frame, in metres.

rho = C_NA r_A and y = -M_B/(M_A+M_B) rho + bias(t). A free PolynomialBias(degree=1) models unknown barycenter position/velocity. The direct mass-ratio derivative is retained separately from dynamics.

Scheduled

Import as basco.Scheduled

Scheduled(channel: object, schedule: object)

Wrap one existing channel to give it its own cadence, pass windows or blackouts on the common plan grid. The wrapper preserves the channel labels, units and native partial method.

A channel observed only at the epochs its own schedule selects.

Scheduled(BodyAttitude("secondary", sigma), Every(2 * u.h)) gives that stream its own cadence on the plan grid. The plan schedule still applies: an epoch is observed only where both allow it. Every other attribute of the wrapped channel (prediction partials, nuisance, values) is forwarded unchanged, so channel classes need no schedule support of their own.

ObservationPlan

Import as basco.ObservationPlan

ObservationPlan(duration: object, cadence: object, channels: tuple, schedule: object = None, schedule_offset: object = 0.0)

Owns one regular base grid and channel definitions. Schedules remove selected observation rows on this grid; they do not skip propagation stages. Arbitrary off-grid observation epochs are not implemented by the fixed-step transport.

Uniform positive elapsed epochs; no t=0 or extra final observation.

A custom channel provides labels, units, positive sigma, and linearize_native(x, parameters) -> (dy/dnative30, direct dy/dphysical_p).

An optional schedule (basco.schedules) selects which grid epochs are observed by every channel; a channel's own schedule (see Scheduled) further restricts that stream. Schedules see epochs + schedule_offset, the mission time of this plan's t=0. The output grid, and hence propagation, is the same with or without a schedule.
