basco.covariance.solvers

From the rows of a least-squares problem to the covariance of its unknowns.

With whitened rows A (observations stacked on a priori information), the covariance of the estimate is (A^T A)^-1. It is computed here without forming A^T A:

  1. Scaling. Each column is multiplied by the scale of its unknown, so that all unknowns are measured in comparable units: A_s = A diag(scales).
  2. Rank. A_s = U S V^T (singular value decomposition). A singular value below rank_rtol times the largest is treated as zero: the observations carry no usable information along that direction (the corresponding row of V^T), which is reported as unobservable.
  3. Covariance. With full rank, A_s = Q R and the covariance of the scaled unknowns is R^-1 R^-T. Multiplying by the scales gives it in physical units.
  4. Without full rank there is no covariance of all unknowns. What is returned instead is the covariance within the determined directions, V_r S_r^-2 V_r^T, together with the unobservable directions. A derived quantity gets a sigma only if it does not depend on an unobservable direction (CovarianceResult.derived).

The same analysis is made for the observations alone and for observations with a priori information, so the result shows what the a priori information added.

Import as basco.covariance.SquareRootInformationSolver

SquareRootInformationSolver(rank_rtol: object = None, name: str = 'scaled QR/SVD')

Default joint scaled solver using SVD for numerical support and QR for covariance/correction. Positive scales and rank_rtol control numerical representation/support; neither adds information.
