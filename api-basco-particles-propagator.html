basco.particles.propagator

The propagator: integrate the binary and a few particles together, with event detection.

The state vector holds the GUBAS state of the binary (30 numbers) followed by six numbers per particle: inertial position [m] and velocity [m/s]. dynamics.py gives its time derivative. One call integrates one binary with all its particles, so they share every step. Use basco.particles.propagate for many particles; it calls propagate_particles batch by batch.

Terminal events. A particle's propagation ends before the final time when

impact       it reaches a body's surface
domain_exit  it enters a body's Brillouin sphere while that body's gravity is the
             exterior Hou series, which is not valid there
grazing      it started on a surface, left it and came back within the tolerances, too
             briefly to be resolved as an arc

Otherwise it is completed: no terminal event by the final time.

The event functions are the signed distances from each particle to each of those boundaries (boundary_distances). One step of the propagator (Propagator.step):

  1. Evaluate the event functions.
  2. A particle within the tolerances of a boundary and approaching it is terminated there.
  3. Otherwise limit the step size so that no particle can cover more than 80% of its distance.
  4. Take the step: adaptive DOP853, or a fixed RK4 step.
  5. If an event function changed sign during the step, locate the event by root finding on the step's dense output, go back to that time, and terminate that particle there.
  6. Save the states at the regular output times the step passed.

IntegratorSettings

IntegratorSettings(method: str = 'DOP853', dt: float = 5.0, max_step: float = 30.0, rtol: float = 1e-10, position_atol_m: float = 0.0001, velocity_atol_m_s: float = 1e-08, attitude_atol: float = 1e-11, spin_atol_rad_s: float = 1e-13, event_distance_m: float = 1e-05, event_time_s: float = 1e-06, max_steps: int = 300000)

Integration settings. Lengths in metres, times in seconds.

method: "DOP853" (adaptive, 8th order) or "RK4" (fixed step dt). dt: the RK4 step, and the first trial step of DOP853. max_step: upper bound on any step. rtol: relative tolerance of DOP853. position_atol_m, velocity_atol_m_s: absolute tolerances for positions and velocities. attitude_atol, spin_atol_rad_s: absolute tolerances for the binary's attitude matrices and spin rates. event_distance_m, event_time_s: event tolerances. A particle is terminated at a boundary once it is within this distance and this estimated time of it. max_steps: give up after this many steps.

propagate_particles

Import as basco.particles.propagate_particles

propagate_particles(model, particles, *, duration, cadence=60.0, integrator=None, fields=None, backend='ad', solar=None, surfaces=None, shadow='none', start_epoch_s=0.0)

Integrate the binary and its particles together; return a StateHistory.

model: BinaryModel: the two bodies, their initial state and mutual gravity. particles: one Particle or a list of them (inertial states at the start). duration: seconds to integrate. cadence: seconds between saved samples. integrator: IntegratorSettings settings; the defaults when None. fields: {"A": field, "B": field}: the gravity of each body on a particle. The exterior Hou series of the binary's own order when a body is not given. backend: "ad" or "analytic": how the binary's equations are evaluated. solar: optional SolarForces. shadow: "none", "sphere" or "mesh" eclipses. surfaces: {"A": surface, "B": surface} for impact detection. A polyhedral field brings its own. start_epoch_s: the time of the initial states; the Sun's position uses this clock.

The saved times are the start, every cadence after it, the finish, and the exact time of each particle's terminal event.
