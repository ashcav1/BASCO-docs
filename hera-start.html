Run and customize Hera covariance

Use this guide to run one rotational case from the Hera paper or start a modified study. BASCO scripts are Python. Your scientific settings belong in your own runner or input file. Keep the installed library and checksum-verified reference data unchanged.

For exact file-editing steps, orbit/spin inputs, figure commands, output folders and a data-reading script, follow Create a covariance run.

Run one paper case

From the BASCO repository root, use the ready-to-edit single-case script:

python3 -B tools/dev.py run examples/hera_one_case.py

Edit its CASE = "AC2" line to choose a different paper state. The script performs fresh propagation and covariance, prints the paper report and writes a standard run under results/. It uses AD and needs the existing ad_environment; figures additionally need plot_environment. See installation.

The calculation itself fits in a short script. Save this as examples/my_hera_run.py so the reference path below is correct:

from pathlib import Path
from basco.benchmarks.hera_study import make_study

reference = Path(__file__).resolve().parents[1] / "reference/hera-20261016"
study = make_study(reference, "AC2")
rows = study.linearize()
result = rows.covariance()
print(result.mass_properties().summary())
print(result.harmonics(max_degree=4).summary())

python3 -B tools/dev.py run examples/my_hera_run.py

make_study constructs the same paper recipe used by the original Hera runner. It does no propagation until linearize() or run() is called. rows retains the design matrix and transport for later statistical comparisons.

The defaults are total Hou gravity order 6, both masses and moments through degree 4 estimated, physical initial-state uncertainty, all four paper measurement streams including Didymos barycentric position, the free barycenter, the combined paper Kaula prior and the nuisance-projected solver. The full duration is 16 mutual orbits with a 75 s RK4 step and 900 s observation cadence. Exact settings and validated results remain the reproduction authority.

To save tables and arrays from the short script, append:

import basco as bc
from basco.benchmarks import hera

folder = bc.export_study(
    rows, result, Path(__file__).resolve().parents[1] / "results",
    label="hera-ac2-g06-e04",
    reports={"paper": hera.hera_report(result), "mass": result.mass_properties()},
)
print(folder)

For plots, add figures=True, theme=bc.PlotTheme(tex=False) to this export call and run with --plot. tex=False uses mathematical text without an external LaTeX installation. tex=True explicitly requires that installation. Export layout and plotting explains the generated files.

Choose a tumbling case

Case Initial state Libration Secondary spin tilt
AC0 Equilibrium, circular planar synchronous reference 0 degrees 0 degrees
AC1 Libration only 10 degrees 0 degrees
AC2 Limited tumbling 10 degrees 20 degrees
AC3 Full tumbling 90 degrees 43.09 degrees

These names select complete initial states, including their declared orbital and orientation assumptions. Rotational case definitions give the other settings. A custom orientation or spin is a new scenario and is not an additional archived paper case. Tumbling develops from the initial state and inertia under the same coupled Hou equations.

To run several predefined cases, use python3 -B tools/dev.py hera_cases AC1 AC3. Full paper runs require the original duration. A short duration=900.0 is useful for testing a script, but it does not reproduce Table 2.

Set your own Dimorphos attitude and spin

To experiment with roll/pitch/yaw and sampled amplitudes before running covariance, use the separate Dimorphos tumbling playground.

For custom Dimorphos tumbling, set the initial attitude and angular velocity explicitly.

Start with the editable custom script:

python3 -B tools/dev.py run examples/hera_custom.py

Its top settings include SECONDARY_TO_PRIMARY_EULER_XYZ_DEG, SECONDARY_SPIN_PERIOD_H and SECONDARY_SPIN_TILT_DEG. The Euler angles define an active rotation from secondary-body components to primary-body components, using extrinsic x, then y, then z rotations. The tilt defines the initial angular-velocity vector's angle from the secondary's positive z axis, in its x-z plane. This is an initial spin direction, not a promise of a constant wobble amplitude during propagation.

The direct API route is equally explicit:

from dataclasses import replace
import numpy as np
from scipy.spatial.transform import Rotation
from basco.benchmarks import hera
from basco.benchmarks.hera_study import make_study

base = hera.build_hera_model(hera.load_inputs(reference), "AC2")
B_to_A = Rotation.from_euler("xyz", [0.0, 3.0, 15.0], degrees=True).as_matrix()
rate = 2.0 * np.pi / (12.0 * 3600.0)  # rad/s, 12-hour spin period
angle = np.deg2rad(30.0)
spin_in_B = rate * np.array([np.sin(angle), 0.0, np.cos(angle)])
initial = replace(base.system.initial_state,
                  B_to_A=B_to_A, omega_secondary=B_to_A @ spin_in_B)
model = replace(base, system=replace(base.system, initial_state=initial,
                                     name="custom Dimorphos initial state"))
study = make_study(reference, model=model, prior="kaula")

BinaryState.omega_secondary is expressed in primary-body components, so the multiplication by B_to_A is required when the input spin vector is expressed in Dimorphos axes. Position and inertial relative velocity are also expressed in primary-body components. See state conventions. The preset state and a custom model are mutually exclusive. A supplied model owns the full initial state; the factory does not silently rebuild its orbit or spin.

Change masses, shapes and the initial orbit

Edit the scientific settings at the top of your copy of hera_custom.py:

What you want to change Setting or public object Units / meaning
Didymos mass PRIMARY_MASS_KG kg; the example scales every mass-weighted primary moment, retaining its normalized shape
Dimorphos mass SECONDARY_MASS_KG kg; the example recomputes density for the selected ellipsoid
Dimorphos shape SECONDARY_SEMI_AXES_M Three positive semi-axes in metres, not full diameters
Dimorphos orientation SECONDARY_TO_PRIMARY_EULER_XYZ_DEG Degrees with the convention above
Dimorphos spin SECONDARY_SPIN_PERIOD_H, SECONDARY_SPIN_TILT_DEG Hours and degrees; the vector is converted into primary axes
Initial relative position POSITION_M Metres, secondary minus primary, resolved in primary axes
Initial relative velocity VELOCITY_M_S m/s, inertial relative velocity resolved in primary axes
Primary spin / orientation Fields of BinaryState in make_model() omega_primary in rad/s and A_to_N as a proper rotation
Fixed gravitational constant G_M3_KG_S2 m^3 kg^-1 s^-2
Primary shape / supplied gravity moments Body with MomentDistribution Complete centered principal-axis mass moments in kg m^degree
Nominal force/torque cutoff GRAVITY_DEGREE Hou total mutual order 2, 4 or 6

POSITION_M = None and VELOCITY_M_S = None retain the paper AC2 starting orbit. If you change the masses, these orbit inputs remain the same: the code does not refit the separation, velocity or period. Supply a mutually consistent state for the new system. The custom model is labelled as a modified study.

For a new primary shape, use mesh moments or an explicit MomentDistribution. Changing only the degree-zero mass entry would leave inconsistent mass-weighted higher moments; the custom example deliberately scales the complete primary table. A homogeneous nominal ellipsoid supplies starting moments; the covariance still estimates the selected independent moment coordinates.

Do not edit src/basco/benchmarks/hera.py, the preserved native code or reference/hera-20261016 to insert new scientific inputs. The reference has a checksum contract and defines the reproducible paper baseline. Your custom BinarySystem, BinaryState and distributions are passed through model=.

Change the covariance assumptions

Choice Where to set it
Nominal Hou gravity order gravity_degree=6 in make_study; must match a supplied model
Degrees to estimate estimate_degrees=(2, 3, 4); distinct from the nominal gravity order
Priors prior="kaula", prior=None, or an explicit collection of prior producers
Total analysis time duration= in seconds
RK4 step dt= in seconds; check refinement when changing it
Derivatives Default AD, or transport=bc.NativeAnalyticTransport()
Measurements, schedules and noise The separate ObservationPlan and CovarianceStudy components below

prior="kaula" deliberately reuses the paper's archived shape laws, even for a custom model. Changing a shape does not refit those laws. For a new shape-informed prior, generate your own shape ensemble and Kaula rule, bind KaulaPrior to the new parameter map, and supply that producer explicitly. Removing priors may expose unresolved directions; keep the reported rank/nullspace diagnostics.

For different observations, reuse the composed physical inputs and construct the study with your own plan:

import basco as bc

plan = bc.ObservationPlan.uniform(
    stop=3600.0, cadence=900.0,
    channels=(bc.RelativePosition(sigma=2.0),
              bc.BodyAttitude("primary", sigma=np.deg2rad(1.0)),
              bc.BodyAttitude("secondary", sigma=np.deg2rad(1.0))),
)
study = bc.CovarianceStudy(
    study.model, study.parameters, plan, study.integrator,
    transport=study.transport_provider, priors=study.priors, solver=study.solver,
)

This intentionally changes the observation model and omits the paper's barycentric stream. To keep that stream, use the documented primary barycentric channel and free barycenter. Observation design specifies epochs, weights and Jacobians; it generates no simulated measurement values.

For native analytic derivatives, select the provider explicitly and choose the native environment:

study = make_study(reference, "AC2", transport=bc.NativeAnalyticTransport())

python3 -B tools/dev.py run --native examples/my_hera_run.py

Changing the runtime flag alone does not change the study's derivative provider. Derivative validation and the opt-in finite-difference checks remain available.

Find settings with search

Open search with the sidebar button or Ctrl/Cmd+K. Try run one Hera case, custom Dimorphos tumbling, change mass, spin rate, estimate degree or Kaula priors. Search includes section links, API names, arguments and class fields. Exact names such as basco.BinaryState.omega_secondary lead to the corresponding reference entry.

Use the paper results to check the baseline, body/state conventions for units and frames, and results to read the exported tables and covariance diagnostics. The single-case script and custom script are the runnable counterparts of this guide.
