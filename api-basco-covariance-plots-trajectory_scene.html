basco.covariance.plots.trajectory_scene

Three-dimensional figures, animations and an interactive page for a particle trajectory with its covariance.

A TrajectoryScene holds what is drawn: the body's shape, the trajectory, the covariance of the position at each epoch, the impact point and its ellipse, and any perturbed trajectories. It is plain data: it can be saved and read back, and drawing it runs no dynamics.

trajectory_figure(scene)              a static figure
animate_trajectory(scene, "a.mp4")    an animation
write_trajectory_html(scene, "a.html")   a page to rotate and step through

A perturbed trajectory drawn in red had no impact within its own propagation time. That is not a statement that it escapes, and the share of red ones is not a probability.

TrajectoryScene

TrajectoryScene(mesh: TriangleMesh, epochs: object, positions_m: object, covariance_m2: object, patch: object = None, enclosing_radius_m: object = None, probability: float = 0.95, statuses: object = None, impact_point_m: object = None, tangent_axes: object = None, tangent_covariance_m2: object = None, surface_contour_m: object = None, hit_points_m: object = None, sample_paths: tuple = (), sample_outcomes: tuple = (), sample_epochs: tuple = (), metadata: dict = field(default_factory=dict), title: str = 'Particle approach', frame: str = 'target body frame', context_bodies: tuple = (), reference_body_visible: bool = True)

Renderer-independent numerical scene in one explicitly named frame. Positions, covariance, domain geometry and every contextual body pose must share that frame and the same epoch alignment. For a fixed target frame the reference mesh is visible by default; inertial multi-body scenes set reference_body_visible=False and supply the moving meshes through context_bodies. Nominal-particle-following views translate by the deterministic nominal curve and retain the same inertial covariance and physical metre scale. The renderer computes no dynamics, covariance or probe classifications.

Everything that is drawn for one trajectory (see the top of this file).

mesh: the target body's shape. epochs: (n,) [s]. positions_m, covariance_m2: (n, 3) and (n, 3, 3) in the frame named by frame. statuses: per epoch, whether the covariance is determined. patch, enclosing_radius_m: the local-field cylinder and the Brillouin radius, drawn as outlines. probability: of the ellipsoids and of the impact ellipse. impact_point_m, tangent_axes, tangent_covariance_m2, surface_contour_m: the impact. sample_paths, sample_outcomes, sample_epochs, hit_points_m: perturbed trajectories. context_bodies: other bodies to draw. metadata, title: text shown with the figure.
