basco.contracts

Structural extension contracts, independent of physics and optional runtimes.

isinstance(component, Contract) checks member presence, not signatures, units or numerical correctness. Consumers continue to validate returned arrays, layouts and identities. The conformance tests exercise those behavioral rules. Optional capabilities have separate protocols so a minimal custom component does not have to implement unused nuisance, schedule or value methods.

ObservationChannel

Import as basco.ObservationChannel

ObservationChannel

Prediction-direction contract: named labels/units, positive noise sigma, and signed local native-state/direct-parameter partials. Actual fixed-data residuals for nonlinear fitting are a separate contract.

Local prediction derivatives in declared SI units and ordered coordinates.

linearize_native returns (dy/dnative30, direct dy/dphysical_parameters), shaped (len(labels), 30) and (len(labels), len(parameters.labels)). Attitude rows are local prediction tangents at the nominal orientation. A derivative known to vanish is an explicit zero array; absence is an error. Fixed-data residuals and retractions for fitting are separate capabilities.

GravityModel

Import as basco.GravityModel

GravityModel

Runtime-checkable minimal gravity declaration with mutual_order. Member-presence checks do not establish backend compatibility or physical correctness; maintained Hou evaluators own the Hou equations.

Common gravity declaration used by parameter and transport selection.

mutual_order sets which moments the model reads. HouGravity is this configuration contract; its native and AD evaluators own the potential. A custom SI potential is the separate DifferentiableGravityModel capability. Compatibility and supported orders are checked by the selected provider, not established by this structural presence check.

Optional declarations: moment_solve_fors=False refuses unsupported moment/harmonic directions, check_model(model) validates body data, and identity_settings() supplies JSON-compatible identity settings.

Optional extension capability for a JAX-traceable SI potential(r, C_AB, T_A, T_B, G). Native analytic support is not implied by supplying an AD-compatible potential.

VariationalEvaluator

Import as basco.VariationalEvaluator

VariationalEvaluator

Callable value-plus-derivative evaluation F, A=dF/dx and B=dF/dT used by the common variational integration owner. No specific force implementation is required by this structural protocol.

One native-state evaluation for the shared variational integrator.

Return (F, A, B), with shapes (30,), (30,30), and (30,n_raw_slots). F=xdot, A=dF/dnative30, B=dF/draw_native in the evaluator's declared raw slot order. Native state uses km, km/s, rad/s and row-major DCMs; raw moments use kg km^(l+m+n). Transport converts raw sensitivities to SI. The integrator requires only this callable, not value or slots.

TransportProvider

Import as basco.TransportProvider

TransportProvider

A replaceable provider owns physics propagation and variational transport; it must return the owned Transport with correct layouts, units and content identity. It does not choose observations, priors or covariance solver.

Nominal states and sensitivities at the requested common epochs.

Return a basco.Transport with the model's native30 ordering, raw_slots in resolved parameter order, and raw/physical sensitivities in SI. Backend preparation, capabilities and integrator support belong here. Optional supported describes capabilities; it is not required of custom providers. Providers do not select observations, noise, priors or solvers.
