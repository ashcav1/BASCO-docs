basco.covariance.analysis

A covariance analysis from start to finish.

analysis = CovarianceAnalysis(model, parameters, observations, integrator=RK4(dt=60.0))
design = analysis.design_matrix()      # the expensive step: integrates the binary and
                                       # its variational equations
result = design.covariance()           # the cheap step: least squares on the rows
print(result.summary())

A covariance analysis asks: if these observations were made with this noise, how well would they determine these parameters? No observation values are needed, only the partial derivatives of the observations with respect to the unknowns (the design matrix H) and the noise. With whitened rows the covariance of the estimate is (H^T H + a priori information)^-1.

The steps, and where each is done:

1. the unknowns                           binary/parameters.py, nuisance.py
2. the nominal trajectory, the state      dynamics/variational_equations.py
   transition matrix and the parameter
   sensitivities at every epoch
3. the rows of H                          design_matrix.py
4. whitening by the observation noise     noise.py
5. a priori information                   priors.py, kaula.py
6. the covariance                         solvers.py
7. reports                                results.py

CovarianceAnalysis

Import as basco.covariance.CovarianceAnalysis, basco.covariance.analysis.CovarianceAnalysis

CovarianceAnalysis(model, parameters, observations, integrator=None, *, partials=None, noise=None, priors=(), solver=None)

Configure the nominal dynamics, estimated parameters, observations, integration, derivative method, noise, priors and covariance solver. Hou AD is selected when transport is omitted. Missing JAX raises an error that identifies the required dependency; there is no automatic native fallback.

The inputs of one covariance analysis.

model: BinaryModel. parameters: EstimatedParameters (or a ParameterSet) of that model. observations: ObservationSchedule. integrator: RK4(dt) by default. partials: "ad" (default) or "analytic": where the partial derivatives of the equations of motion come from; or a variational-equations object. noise: observation noise, when it differs from the sigmas of the observation types: a vector of sigmas per row, a covariance matrix, or a noise object. priors: a priori information (see priors.py), none by default. solver: SquareRootInformationSolver by default.

CovarianceAnalysis.design_matrix

design_matrix(self, *, variational_solution=None)

Propagate once and form immutable prediction rows. Pass an existing transport only when physical inputs, coordinate map, schedule, numerical settings and provider identity match.

Integrate the variational equations and assemble the DesignMatrix.

variational_solution reuses a solution computed earlier (for example with other observation types at the same epochs) instead of integrating again. It is accepted only if it was computed for this model, these parameters, these epochs and this integrator.
