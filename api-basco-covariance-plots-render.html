basco.covariance.plots.render

The standard figures of a covariance analysis, drawn from its report tables.

Nothing is computed here: every number comes from a ResultsTables object (see results_tables.py). Each figure is a PlotDefinition, a name with a function draw(tables, theme) that returns a Matplotlib figure. render draws a list of them and saves each as PNG, SVG and PDF. To add a figure of your own, write such a function and pass your PlotDefinition in plots=.

A PlotDefinition comparing the uncertainties of several analyses as grouped bars.
