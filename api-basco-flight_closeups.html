basco.flight_closeups

Target-only metre-scale views of saved position covariance and surface shadows.

Surface shadows are fixed-time orthographic position marginals. The separately supplied event-corrected contact contour remains a fixed reference. No dynamics, measurements, information updates or post-contact covariance are generated.

SurfaceProjectionHistory

SurfaceProjectionHistory(centres_uv_m: object, covariance_uv_m2: object, available: object, point_m: object, tangent_axes: object, face_triangle_m: object)

Current-position marginal projected into one actual smooth mesh facet. This is a fixed-time geometric projection, distinct from event-corrected first-contact covariance. The availability flag requires the whole supported-rank confidence ellipse to remain inside that same facet.

Current-position shadows in a fixed smooth facet chart, never landing forecasts.

centres_uv_m [N,2], covariance_uv_m2 [N,2,2], point_m [3], tangent_axes [3,2] and face_triangle_m [3,3] use physical metres. available marks complete 95% contours contained in that actual mesh facet. Unsupported contours are NaN.

surface_projection_history

surface_projection_history(scene)

Compose u=E.T@(r-p) and P_u=E.T@P_r@E from the complete target-frame marginal. Uses the resolved contact chart, actual mesh facet and analytic barycentric contour bounds. The scene must provide fixed target geometry, contact point and orthonormal tangent axes; unsupported epochs remain unavailable.

Project the current position marginal along the fixed contact-facet normal.

The complete two-dimensional confidence ellipse must lie in one actual facet. A finite exterior/unsupported epoch is not promoted to a landing prediction. The chi-square dimension is the supported rank of the projected marginal.

animate_closeup

animate_closeup(scene, destination, *, camera, time_window=None, theme=None, frames=180, fps=20, dpi=150)

Write a target-only MP4 with fixed body axes and camera. An optional continuous time_window selects saved supported epochs. Mean and covariance use explicitly labelled convex linear display interpolation, preserving source arrays and avoiding unsupported/contact-ended intervals.

Animate a target-only 3D ROI; convex display interpolation preserves PSD.

A time window selects supported saved epochs. No interpolation crosses the contact endpoint or an unsupported epoch; source arrays are not modified.
