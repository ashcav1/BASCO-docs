basco.covariance.design_matrix

The design matrix H: the partial derivatives of every observation with respect to every unknown.

An observation y at epoch t_k depends on the unknowns through the state x(t_k):

dy / d(initial state deviation) = Hy Phi_k J
dy / d(bias coefficients)       = the observation type's own partials
dy / d(physical parameters)     = Hy Psi_k + direct

Hy = dy / d GUBAS state            from the observation type
Phi_k, Psi_k                       state transition matrix and parameter sensitivities
                                   (the VariationalSolution)
J = d GUBAS state / d state deviation at the initial time
direct                             dependence of y on a parameter at a fixed state

assemble_design_matrix stacks these rows for every epoch and observation type. The unknowns are referred to the initial time: the state columns are the initial state deviation.

A DesignMatrix keeps the rows unwhitened, in physical units. Noise, a priori information and the solver are applied when covariance() is called, so they can all be changed without integrating again.

DesignMatrix.with_parameters

with_parameters(self, parameters, *, priors=())

Select or reorder an existing physical-coordinate subset while retaining local state/nuisance columns. Omitted coordinates become fixed: this is conditioning, not marginalization. Priors reset to empty unless supplied. New directions or changed gravity require new propagation.

The design matrix for a subset of the physical parameters, the others held fixed at their nominal values. Nothing is integrated: columns are removed.

parameters must be a subset of the current ones for the same model, defined the same way. The initial state and the biases stay as they are.

Fixing a parameter is not the same as estimating it and ignoring the answer: a fixed parameter is assumed to be known exactly. A priori information is not carried over; give the priors that apply to the new set. To add parameters or change the gravity model, make a new analysis.

DesignMatrix.covariance

covariance(self, *, noise=None, priors=None, solver=None, rank_rtol=None, consider=None)

Rewhiten/solve retained rows with selected noise, priors or solver; zero new dynamics evaluations. priors=() explicitly removes prior information. Diagnose rank before interpreting uncertainties.

The covariance of the unknowns from these rows: a CovarianceResult.

noise, priors, solver: replace the defaults for this call. rank_rtol: singular values below this fraction of the largest count as zero. consider: ConsiderParameters, to treat some unknowns as consider parameters (see consider.py); the result is then a ConsiderResult.

Nothing is integrated, so this takes a fraction of a second.
