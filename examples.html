Example scripts

The scripts in examples/ are meant to be copied and edited. Each has its settings as plain variables at the top and then runs from top to bottom, in about a page. None takes command-line options: to change something, edit the variable.

source tools/activate
python examples/particles/1_launch_from_surface.py

Outputs go to results/, which Git ignores. An example that saves a covariance analysis writes into a new folder on every run.

Scripts that take options

The figures and numbers in this manual were produced by scripts that take command-line options and write checksummed result folders. They live in tools/evidence/ and call the same library functions as the examples. Use them to reproduce a figure exactly; use the examples to learn and to start your own work.

Evidence script Corresponding example
tools/evidence/synthetic_binary_artifact.py basics/synthetic_binary.py
tools/evidence/hera_all_cases.py hera/all_cases.py
tools/evidence/hera_degree_trades.py hera/degree_trades.py
tools/evidence/hera_consider_and_histories.py hera/consider_and_histories.py
tools/evidence/hera_multi_arc.py hera/multi_arc.py
tools/evidence/hera_kaula_priors.py hera/kaula_priors.py
tools/evidence/particle_covariance_cases.py trajectory/particle_covariance.py
tools/evidence/particle_from_saved_hera_analyses.py trajectory/from_saved_hera_analyses.py
tools/evidence/local_field_cases.py trajectory/local_field_from_hou.py, local_field_direct.py
tools/evidence/landing_covariance.py trajectory/impact_covariance.py
tools/evidence/mission_scale_trajectories.py trajectory/long_trajectories.py

Each prints its options with --help, for example:

python tools/evidence/hera_all_cases.py --help

Some of these scripts still use earlier words in their options (--derivatives manual, --backend native); both mean the hand-derived analytic partials.

The separate Dimorphos tumbling playground runs the nominal dynamics only, for experiments with attitude and spin.
