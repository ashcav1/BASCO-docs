LinearizedStudy.with_parameters

with_parameters(self, parameters, *, priors=())

Select or reorder an existing physical-coordinate subset while retaining local state/nuisance columns. Omitted coordinates become fixed: this is conditioning, not marginalization. Priors reset to empty unless supplied. New directions or changed gravity require new propagation.

Condition on fixed coordinates and reuse a subset of these solve-fors.

The nominal model, raw physical derivative directions and treatment of the initial state must stay unchanged. This is column selection, not marginalization: omitted parameters are held fixed at their nominal values. Local state and observation-nuisance columns remain free.

Priors default to empty. Supply the desired prior producers explicitly for the new layout; projecting old prior rows could inadvertently add information when previously uncertain coordinates become fixed. Changing gravity, adding directions or changing coordinate maps needs a new study/transport instead.

assemble_design(parameters, plan, transport, *, noise=None, priors=(), solver=None, specification=None, coordinates=None)

Combine local prediction directions with common-epoch transport.
