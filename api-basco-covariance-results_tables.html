basco.covariance.results_tables

The report tables of an analysis in one form, from which every file format is written.

ResultsRow      one quantity: label, value, sigma, unit and status
ResultsTable    a named list of rows (for example the mass properties)
ResultsTables   all tables of one analysis, with a title and a summary

make_results_tables builds them from a result; write_results_tables writes Markdown, CSV, LaTeX and JSON (and figures) from them, so that all formats show the same numbers.

make_results_tables

Import as basco.covariance.make_results_tables

make_results_tables(result, *, design=None, reports=None, title='BASCO covariance study', provenance=None)

Build the shared result dataset used by tables and plots. Supply rows to retain the linearization settings; custom derived reports can be added to the same presentation.

The ResultsTables of a result.

reports ({name: report}) chooses the tables; by default the mass properties, the second-degree quantities and the harmonics that the parameters allow. design adds information about the observations.
