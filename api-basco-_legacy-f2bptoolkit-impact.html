basco._legacy.f2bptoolkit.impact

Legacy compatibility reference. Prefer current BASCO workflows; copied implementation details are not new development targets.

Surface-impact detection for a point particle, robust across all three shape types (sphere, ellipsoid, polyhedron).

Two things are exported:

  • signed_distance(p_body, shape, mesh=None) — signed distance from a body-frame point to the surface. Positive outside, negative inside, zero on the surface. Shape-agnostic.

  • make_impact_event(shape, to_body) — build a solve_ivp-ready event callable. to_body(t, x) must map an inertial position to the secondary's body frame. The returned event is terminal and fires on the outside->inside crossing, so the integrator stops exactly at impact.

The polyhedron mesh is built once (inside make_impact_event), not on every call.

signed_distance

signed_distance(p_body, shape, mesh=None)

Signed distance from body-frame point(s) p_body to the surface.

Positive outside, negative inside, zero on the surface. For a sphere this is the true distance in metres; for an ellipsoid it is the normalised level-set value (same sign, crosses zero on the surface); for a polyhedron it is the exact signed distance in metres.

make_impact_event

make_impact_event(shape, to_body)

Build a terminal solve_ivp event that fires when the particle crosses the secondary's surface.

Parameters

shape : SphereShape | EllipsoidShape | PolyhedronShape The secondary's shape (the landing target). to_body : callable to_body(t, x_inertial) -> p_body maps the particle's inertial position to the secondary body frame at time t.

Returns

event : callable event(t, y) for solve_ivp. y[:3] is the inertial position. Terminal, fires on the outside->inside crossing.
