draw_kaula

draw_kaula(rules, theme=None, *, body_names=None, reference_laws=None, show_density=False, minimum_magnitude=0.0, show_ensemble_legend=False, show_body_names=True)

Return zonal/nonzonal panels for any number of body laws.

reference_laws optionally maps (body,channel) to (label,PowerLaw). Figure 3 uses archived shape clouds; no shape samples are generated here. Each panel follows the paper's 4.8 by 3.2 inch allocation; theme.width scales the whole figure. Curve legends stay inside their panels. The optional ensemble legend identifies points already described in captions. Set show_body_names=False when body identities are given in the caption.

render_kaula

render_kaula(rules, output, theme=None, **draw_options)

Render fitted Kaula/ensemble data with the shared scientific plot theme. It does not propagate dynamics.

Atomically publish figures/tables/ensembles/results with a final manifest.

An existing output directory is never overwritten. A failed fit/render leaves no completed-looking output directory; no shape work occurs here.
