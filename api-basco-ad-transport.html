ADTransport

Import as basco.ad.ADTransport

ADTransport(name: str = AD_PROVIDER_NAME, supported: str = 'AD (JAX float64) of the copied Hou mutual orders 2/4/6 or any gravity with an SI potential(); principal axes; autonomous; fixed RK4; uniform cadence')

Default Hou derivative provider: a separate JAX-compatible Hou value/equations copy, differentiated automatically. Construction is lazy; use requires basco[ad] and float64 JAX. The native analytic implementation remains independent.

TransportProvider: same physics and integrator, AD instead of manual partials.

Pass transport=ADTransport() to CovarianceStudy. Gravity comes from the model: HouGravity uses the copied Hou potential; a custom gravity with an SI potential() is differentiated the same way. The augmented RK4 stages are the shared integration.integrate_variational used by the native provider.
