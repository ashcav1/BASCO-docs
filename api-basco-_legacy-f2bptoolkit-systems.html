basco._legacy.f2bptoolkit.systems

Legacy compatibility reference. Prefer current BASCO workflows; copied implementation details are not new development targets.

Named binary-asteroid configurations.

Reference systems, in one place, with their sources recorded. Scattering these across scripts is how two studies end up quietly using different numbers for the same body -- which happened to the benchmark once already in this project.

Each entry is a :class:SystemConfig. Call :meth:build for a configured Simulation at the doubly-synchronous (or observed) state, or :meth:variational_problem for one wired for covariance work.

Equilibrium note

For a doubly synchronous system the spin rate is NOT the Keplerian mean motion: the quadrupole terms shift it. :meth:equilibrium_rate solves the actual condition r n^2 = (1/m) dU/dr using the analytic potential gradient, which for 617 Patroclus is a 0.14% correction -- small, but it moves the linearised manifold periods by a few percent, which is the difference between agreeing with published values and not.

SystemConfig.integrals

integrals(self, order: Optional[int]=None)

Both bodies' mass-weighted inertia integrals, honouring the shapes.

Returns None when BOTH bodies are ellipsoids, which is the signal to callers to take the untouched closed-form path. That is deliberate rather than tidy: an all-ellipsoid run must reproduce the published numbers bit-for-bit, and routing it through the mesh machinery would agree only to rounding -- which the regression suite refuses.
