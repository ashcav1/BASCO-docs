basco.spacecraft.dynamics

Restricted full three-body equations: a full rigid binary and a test particle.

The stored state is mixed only at this private numerical boundary: native30 binary coordinates followed by six SI spacecraft coordinates. Raw-parameter columns everywhere in this evaluator are mass-weighted SI moments. The existing physical parameter Jacobian is applied later, exactly once.

RestrictedDynamics

Import as basco.spacecraft.RestrictedDynamics

RestrictedDynamics(model, parameters, *, backend='ad', field_order=None)

Composes the retained Hou binary with two asteroid-to-particle fields. Native30 binary and SI6 spacecraft are integrated at common stages. AD is default; backend='native' selects hand-derived potential/binary partials. No observations or estimator are constructed.

Compose Hou binary dynamics with a massless spacecraft's inertial field.

model is BinaryDynamics; parameters is its Parameters/ResolvedParameters. backend selects 'ad' (default, lazy JAX) or 'native' analytic derivatives. field_order defaults to the mutual order and may be 2/4/6 up to that order. The field is evaluated only outside each declared enclosing sphere. This first slice has no observations, stochastic forces, contact or thrust.
