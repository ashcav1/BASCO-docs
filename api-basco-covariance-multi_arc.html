basco.covariance.multi_arc

Several arcs analysed together: each arc has its own initial state, all share the physical parameters.

An arc is a stretch of observations with its own DesignMatrix. Combining arcs stacks their rows, with the columns arranged so that

  • each arc's initial state deviation and biases are separate unknowns, and
  • the physical parameters (masses, gravity) are the same unknowns for all arcs.

Nothing is integrated here. There is no constraint that one arc's final state equals the next arc's initial state, and no process noise.

MultiArcDesignMatrix.covariance() gives the joint covariance. estimate and MultiArcBatchLeastSquares use the same rows for actual fitting.

MultiArcDesignMatrix

Import as basco.covariance.MultiArcDesignMatrix

MultiArcDesignMatrix(arcs, *, shared_parameters=None, priors=(), solver=None)

Assemble arbitrary already-design arcs into named local columns plus shared physical columns. Default measurement noise is independent across arcs; a full joint whitening model can express cross-arc correlation.

Several arcs with shared physical parameters.

multi = MultiArcDesignMatrix({"early": early_design, "late": late_design})
covariance = multi.covariance()

arcs: {name: DesignMatrix}. shared_parameters: names of the parameters common to all arcs; by default all physical parameters, which every arc must then have. The others, and always the initial states and biases, are separate for each arc. priors: a priori information on shared parameters; give it here, once. A priori information inside an arc may only concern that arc's own unknowns.

Shared parameters must have the same definition, unit and nominal value in every arc. Unknowns of an arc are labelled with the arc's name.

MultiArcBatchLeastSquares

Import as basco.covariance.MultiArcBatchLeastSquares

MultiArcBatchLeastSquares(max_iterations: int = 15, step_rtol: float = 1e-09, gradient_rtol: float = 1e-09, max_backtracks: int = 12, backtrack_factor: float = 0.5, armijo: float = 0.0001, rank_rtol: object = None, allow_rank_deficient: bool = False)

Generic callback-based nonlinear batch/MAP loop with relinearization and objective backtracking. Callers supply correctly signed residuals and physical retractions. Mission-style binary observed-value adapters, recovery validation and multiple filters remain future work.

Nonlinear batch least squares by Gauss-Newton iteration.

You supply two functions:

linearize(state) -> (MultiArcDesignMatrix, residuals)
    integrate your model at ``state`` and return the design matrices and the
    residuals (observed minus predicted) of every arc.
retract(state, correction, layout) -> new state
    apply a correction of the unknowns to ``state`` (masses stay positive,
    attitudes are rotated, and so on). It must not modify its input.

Each iteration solves the linear problem, then shortens the step if the weighted sum of squares does not decrease (max_backtracks, backtrack_factor, armijo). It stops when the step or the gradient is small (step_rtol, gradient_rtol) or after max_iterations.

Keep the data, the noise and the a priori means the same throughout. A fit that does not converge is returned as such, not hidden.
