basco.flight_plotting

Three-dimensional presentation of supplied spacecraft and contact covariance.

This module never integrates dynamics or classifies an impact. It draws owned body-frame geometry and uncertainty supplied by a numerical application. A red probe means no contact within that probe's declared forecast, not escape or a probability. Optional source metadata makes those assumptions visible in every export. Matplotlib and animation encoders remain lazy presentation dependencies.

A finite marginal position region, including declared degeneracy.

Full rank uses chi-square with three degrees of freedom, not a six-state joint contour or three independent one-dimensional sigma intervals. Finite singular distributions use their supported rank; unknown directions must instead be excluded by FlightScene.statuses and are never zeroed here.

FlightScene

FlightScene(mesh: TriangleMesh, epochs: object, positions_m: object, covariance_m2: object, patch: object = None, enclosing_radius_m: object = None, probability: float = 0.95, statuses: object = None, contact_point_m: object = None, tangent_axes: object = None, tangent_covariance_m2: object = None, surface_contour_m: object = None, hit_points_m: object = None, sample_paths: tuple = (), sample_outcomes: tuple = (), sample_epochs: tuple = (), metadata: dict = field(default_factory=dict), title: str = 'Spacecraft approach', frame: str = 'target body frame', context_bodies: tuple = (), reference_body_visible: bool = True)

Renderer-independent numerical scene in one explicitly named frame. Positions, covariance, domain geometry and every contextual body pose must share that frame and the same epoch alignment. For a fixed target frame the reference mesh is visible by default; inertial multi-body scenes set reference_body_visible=False and supply the moving meshes through context_bodies. Nominal-spacecraft-following views translate by the deterministic nominal curve and retain the same inertial covariance and physical metre scale. The renderer computes no dynamics, covariance or probe classifications.

A numerical-data-only scene, reusable for any target mesh and dynamics.

Positions/covariance and every context-body pose share the declared scene frame at each epoch; the application includes uncertainty in that frame. The reference mesh is fixed in scene coordinates. For an inertial scene, set reference_body_visible=False and supply every moving body as context. A fixed cylinder belongs to a visible fixed reference-body scene. Covariance is a marginal position covariance. Unsupported/NaN epochs keep their nominal path but do not produce an ellipsoid. A supplied tangent covariance is event-corrected contact covariance, not fixed-time position covariance. Those two uncertainties are displayed separately.

sample_paths are deterministic unweighted confidence probes. Their outcomes come from the propagation/contact application, never from this renderer. Optional sample_epochs makes animation reveal each path on its own clock; without it, complete probe paths are static reference overlays.
