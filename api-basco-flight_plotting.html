basco.flight_plotting

Three-dimensional presentation of supplied spacecraft and contact covariance.

This module never integrates dynamics or classifies an impact. It draws owned body-frame geometry and uncertainty supplied by a numerical application. A red probe means no contact within that probe's declared forecast, not escape or a probability. Optional source metadata makes those assumptions visible in every export. Matplotlib and animation encoders remain lazy presentation dependencies.

confidence_ellipsoid(mean, covariance, *, probability=0.95, resolution=48)

Construct a marginal position probability region from mean and PSD covariance. Full rank uses chi-square(3); a declared finite singular distribution uses its supported rank. Missing or unresolved covariance is not converted to a zero-radius ellipsoid. Positions and axes are metres.

FlightScene

FlightScene(mesh: TriangleMesh, epochs: object, positions_m: object, covariance_m2: object, patch: object = None, enclosing_radius_m: object = None, probability: float = 0.95, statuses: object = None, contact_point_m: object = None, tangent_axes: object = None, tangent_covariance_m2: object = None, surface_contour_m: object = None, hit_points_m: object = None, sample_paths: tuple = (), sample_outcomes: tuple = (), sample_epochs: tuple = (), metadata: dict = field(default_factory=dict), title: str = 'Spacecraft approach', frame: str = 'target body frame')

Renderer-independent numerical scene in one fixed named target-body frame: arbitrary mesh, epochs, positions, marginal covariance, optional enclosing sphere/cylinder, event contact and explicitly classified probe paths. It owns no force evaluator or original source factor. Unavailable epochs omit ellipsoids. Probe outcomes come from propagation and never from the renderer.

A numerical-data-only scene, reusable for any target mesh and dynamics.

Positions/covariance are in one fixed named target-body frame at each epoch; the application must include uncertainty in that changing frame. Mesh vertices, cylinder and enclosing radius use the same frame/metres. Covariance is a marginal position covariance. Unsupported/NaN epochs keep their nominal path but do not produce an ellipsoid. A supplied tangent covariance is event-corrected contact covariance, not fixed-time position covariance. Those two uncertainties are displayed separately.

sample_paths are deterministic unweighted confidence probes. Their outcomes come from the propagation/contact application, never from this renderer. Optional sample_epochs makes animation reveal each path on its own clock; without it, complete probe paths are static reference overlays.
