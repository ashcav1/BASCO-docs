basco.tumbling_viewer

Dependency-free HTML playback of saved nominal secondary attitude samples.

The writer draws supplied rotations and diagnostics. It does not propagate a trajectory, interpolate attitude, or compute covariance.

write_tumbling_viewer

write_tumbling_viewer(destination, epochs_s, body_axes_hill, angles_deg, spin_body_deg_s, *, axes_m=None, label='', sequence='XYZ', metadata=None)

Write a standalone offline HTML saved-sample viewer. Rotation matrices map secondary-body components into instantaneous Hill coordinates. angles_deg columns are roll/pitch/yaw; pass segment_ids in metadata for locally unwrapped curves so disconnected charts are never joined. An optional physical ellipsoid illustrates nominal semiaxis proportions. No simulation or interpolation runs in the browser.

Write a standalone offline viewer of saved attitude samples and return its path.

Parameters

destination : path-like Output HTML file. Its parent directory is created if needed. epochs_s : array-like, shape (N,) Strictly increasing nonnegative elapsed times in SI seconds. body_axes_hill : array-like, shape (N, 3, 3) Proper rotations mapping secondary-body components into the instantaneous orbital RTN/Hill frame. Columns are the body axes in Hill components. angles_deg : array-like, shape (N, 3) Roll, pitch and yaw samples in degrees. Nonfinite values serialize as JSON null and appear as unavailable, never as zero. spin_body_deg_s : array-like, shape (N, 3) Finite angular-velocity components in secondary-body axes, in deg/s. axes_m : array-like, shape (3,), optional Positive physical ellipsoid semiaxes aligned with the supplied body axes. Without these, the report explicitly draws axes only. label : str Human-readable report title. sequence : {"XYZ", "ZYX"} Intrinsic Euler convention: 123 XYZ or 321 ZYX. Angle columns remain roll about x, pitch about y, yaw about z in either convention. metadata : dict, optional Strict plain JSON report metadata. singular_mask may contain N booleans; these samples show unavailable Euler angles. segment_ids may contain N integers (nonnegative local chart IDs or -1 unavailable). angle_display names the saved angle display. Local report filenames anywhere in this mapping become links beside the viewer.

Notes

Playback selects actual saved samples without attitude interpolation. The camera is fixed in Hill axes; changing playback speed changes only display timing. No simulation, estimation, smoothing or covariance is performed.
