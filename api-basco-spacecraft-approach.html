basco.spacecraft.approach

Local-field RF3BP approach using shared integration and original source factors.

The binary still obeys the retained Hou equations. Local coefficient columns are explicit particle-force coordinates, mapped to the original joint source once. This module supplies no observation, estimator or alternate integrator.

Own the common-stage approach transport, original source/initialization, force-coordinate map, fixed-time target-body position history and separate event-corrected contact report.
