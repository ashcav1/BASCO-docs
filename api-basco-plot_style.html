PlotTheme.sample_colors

sample_colors(self, positions)

Sample the paper colormap at explicit positions between zero and one. Returned colors preserve the supplied position order and can be shared across independent figures.

Sample the paper palette at fractional positions, excluding its dark toe.

Positions are in [0, 1]; zero maps to 0.14 in the continuous map. This is the same discrete-series convention as the Hera paper.

BarLayout

Import as basco.BarLayout

BarLayout(group_by: str = 'parameter', panel_columns: int = 1, figsize: tuple | None = None, colors: tuple = (), hatches: tuple = (), legend: str = 'figure', legend_location: str = 'upper right', legend_columns: int = 4, legend_font_size: float | None = None, legend_headroom: float = 1.0, tick_rotation: float | None = None, tick_font_size: float | None = None, tick_line_spacing: float | None = None, show_titles: bool = True, panel_letters: bool = False, gain_baseline: float | None = None, subplot_adjustments: tuple = (), legend_options: tuple = ())

Configure grouped-bar geometry independently of the result data. Dimensions are inches. group_by='parameter' puts quantities on the horizontal axis and cases in the legend; 'case' exchanges those roles. Colors and optional hatches follow legend order.

Presentation choices for a grouped uncertainty comparison.

group_by='parameter' puts quantities on the x axis and cases in the legend. 'case' exchanges these roles (as in Hera Figure 5). Figure dimensions are inches. Colors and hatches follow legend order. A gain baseline changes only bar geometry, never the reported ratio.
