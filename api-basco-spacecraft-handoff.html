basco.spacecraft.handoff

Retained binary handoffs and named spacecraft initial-condition Jacobians.

A handoff changes the integration origin without changing the source error coordinates. Original native matrices, STM and SI raw sensitivities remain unprojected. The source-to-state map is composed with later transport once.

BinaryHandoff.from_transport

from_transport(cls, transport, parameters, *, epoch_s, reference_epoch_s=0.0)

Select exactly one stored epoch. No interpolation, extra propagation, projection or covariance solve occurs. source_jacobian includes the binary STM lift and already-accumulated parameter sensitivity from the original reference epoch.

Select one exact on-grid epoch from a validated owned binary Transport.

epoch_s and reference_epoch_s are elapsed physical seconds on the same clock; transport.epochs remain relative to the original binary start. No interpolation, propagation, attitude projection or covariance solve is performed. Identity, native layout, raw SI slots and original model are checked before selecting the stored state and sensitivities.

SpacecraftInitialization

Import as basco.spacecraft.SpacecraftInitialization

SpacecraftInitialization(parameters: object, state: object, layout: CoordinateLayout, initial_jacobian: object, raw_parameter_jacobian: object, reference_epoch_s: float, release_epoch_s: float, metadata: dict)

Combined release state and named original-source Jacobian J0. The raw map uses mass-weighted SI moments. Downstream transport composes Phi J0 + Psi raw_map once, preserving the original source layout and cross covariance. Ordinary callers pass initial and handoff to RestrictedDynamics.propagate; inspect trajectory.initialization for the resulting map.

Nominal combined state and its named original-source initial map.

state is native30 plus inertial SI6 at release_epoch_s. initial_jacobian is J0 in layout order. raw_parameter_jacobian maps those same source axes to mass-weighted SI moments. Later maps use Phi @ J0 + Psi @ raw_map; the integrator still starts with identity36 and zero raw sensitivity. Source reference and physical release epochs are intentionally distinct.
