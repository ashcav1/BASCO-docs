basco.ad.hou_tables

NumPy copy of the Hou/GUBAS expansion tables used by the AD backend.

Copied function by function from native/legacy/gubas_core.cpp (see SOURCE). Names, loop order and arithmetic follow the C++ so the two read side by side:

factorial, tk_calc, t_ind,     expansion coefficients (Hou 2016, Table 1)
a_calc, b_calc
potential_terms                the loops of u_tilde() and potential()
rotation_terms                 the loops of inertia_rot()

Only the evaluation is reorganized. The loops run once here and record their nonzero terms; basco.ad.gravity evaluates those terms as array contractions so JAX can differentiate them. potential_numpy and rotate_numpy evaluate the same terms with NumPy, so the copy is checkable against the native kernels without JAX installed.

Units follow the C++: km, kg, s. Inertia integrals are mass weighted (T^000 is the mass in kg) and flattened as l + mdim + ndim**2 with dim = order + 1, the order used by SimConfig.TA_override/TB_override.
