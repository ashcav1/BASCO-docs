export_covariance_history

Import as basco.export_covariance_history

export_covariance_history(history, destination, *, title='BASCO covariance history')

Write a mapped history, full output covariance and source Jacobians.

The folder contains human-readable metadata and long-form CSV, plus named checksummed NPY arrays. NaN denotes unavailable numeric covariance; CSV uses an empty uncertainty cell plus the explicit support status. Existing exports are never overwritten. This function does not run any solver.
