CovarianceStudy

Import as basco.CovarianceStudy, basco.covariance.CovarianceStudy

CovarianceStudy(model, parameters, observations, integrator=None, *, transport=None, noise=None, priors=(), solver=None)

Configure the nominal dynamics, estimated parameters, observations, integration, derivative method, noise, priors and covariance solver. Hou AD is selected when transport is omitted. Missing JAX raises an error that identifies the required dependency; there is no automatic native fallback.

One convenient workflow using the same explicit extension contracts.
