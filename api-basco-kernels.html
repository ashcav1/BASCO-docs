PreparedDerivatives

PreparedDerivatives(order, G, TA_flat, TB_flat)

One coefficient preparation and one tensor evaluation per RK stage.

Exact input equality controls the one-entry memo. Its owned key contains r and all nine attitude entries; off-manifold attitude derivatives are preserved. No global mutable kernel or approximate trajectory cache.
