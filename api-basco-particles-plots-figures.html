basco.particles.plots.figures

Figures of propagated trajectories.

plot_trajectories(trajectories, frame="Dimorphos")   trajectories in a body-fixed frame
plot_trajectories(trajectories, frame="rotating")    in the rotating frame of the binary
plot_impact_map(trajectories)                        where the particles impact
plot_altitude(trajectories)                          altitude against distance and time
plot_outcomes(trajectories, by={"attitude": "Attitude"})   share of each outcome per group
plot_impact_statistics(trajectories)                 impacts over time, v2 against v1
plot_summary([a, b, c])                              one table row per set of trajectories

Every figure is a 16:9 page with two title lines: the label of the trajectories, then which particles are drawn and in which frame. To draw only some particles, select them first:

impacting = trajectories.impacting("Dimorphos")
plot_trajectories(impacting, frame="Dimorphos")

Colour shows one number per particle (v1 by default). Line style and end marker show the outcome. Give file to save a PNG, or deck (a SlideDeck) to add a page to a PDF. With neither, the function returns the open Matplotlib figure.

plot_trajectories

Import as basco.particles.plot_trajectories, basco.particles.plots.plot_trajectories

plot_trajectories(trajectories, frame=None, color='v1', color_limits=None, zoom=1.0, fit=0.95, file=None, deck=None)

The trajectory of every particle, in one frame.

frame: a body's name, for that body's fixed frame (left: the whole body; right: around the site, when the particles started from a site on that body); or "rotating" for the binary's rotating frame, or "inertial" (left: from 35 degrees above the orbit plane; right: from above). Default: the body the particles started from, or "rotating". color: what colours the trajectories: "v1", "v2", "flight_time" or an initial-conditions column. zoom: 2 shows twice as much around the default frame; "fit" holds the fraction fit of the trajectories.
