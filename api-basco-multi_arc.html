basco.multi_arc

Independent arc states and shared physics, assembled without new dynamics.

Each input is a frozen LinearizedStudy. Arc elapsed times need not overlap: there is no implicit state continuity constraint or process-noise model. Data noise is independent between arcs unless a joint whitening model is supplied. estimate solves the retained local linear problem; nonlinear orbit fitting requires rebuilding each arc's nominal trajectory and prediction rows.

MultiArcStudy

Import as basco.MultiArcStudy

MultiArcStudy(arcs, *, shared_parameters=None, priors=(), solver=None)

Assemble arbitrary already-linearized arcs into named local columns plus shared physical columns. Default measurement noise is independent across arcs; a full joint whitening model can express cross-arc correlation.

Compose frozen arcs with local states/nuisance and shared parameters.

Example: multi = MultiArcStudy({"early": early_rows, "late": late_rows}) covariance = multi.covariance() fit = multi.estimate({"early": early_residual, "late": late_residual})

By default every arc must select the same physical parameters, all shared. An explicit shared_parameters sequence shares only those IDs; every other coordinate is arc-local. Initial-state errors are always local. Shared nominal values, units and physical coordinate definitions must agree exactly; unshared nuisance nominal values may differ between arcs. The first arc supplies the recorded shared scales.

Priors touching shared coordinates belong in this study's priors once. Arc priors may constrain local coordinates; shared arc priors are rejected. Global correlated priors can connect fully qualified arc coordinate IDs.

MultiArcBatchEstimator

Import as basco.MultiArcBatchEstimator

MultiArcBatchEstimator(max_iterations: int = 15, step_rtol: float = 1e-09, gradient_rtol: float = 1e-09, max_backtracks: int = 12, backtrack_factor: float = 0.5, armijo: float = 0.0001, rank_rtol: object = None, allow_rank_deficient: bool = False)

Generic callback-based nonlinear batch/MAP loop with relinearization and objective backtracking. Callers supply correctly signed residuals and physical retractions. Mission-style binary observed-value adapters, recovery validation and multiple filters remain future work.

Gauss-Newton batch/MAP with explicit callback-owned nonlinear physics.

linearize(state) must return (MultiArcStudy, residuals), rebuilding nominal predictions, analytic rows and prior references at that state. Keep data, noise, coordinate IDs/units and prior means fixed throughout the solve. In particular, an informative prior must keep an explicit fixed mean; recentering its mean on every iterate would change the statistical problem.

retract(state, physical_correction, layout) returns a new state and handles named parameters, arc nuisance states, positivity and SO(3) retractions. Callbacks must not mutate their input state. Backtracking uses the actual relinearized data-plus-prior objective. Failed convergence is returned explicitly; no damping/line-search term enters the reported covariance.
