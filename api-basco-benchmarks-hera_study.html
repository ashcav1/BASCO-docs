basco.benchmarks.hera_study

Compose the Hera covariance recipe with explicit data and model inputs.

This module owns study composition only. Nominal bodies and states, parameter maps, observations, priors, transport and numerical solving keep their existing owners. The four archived paper cases remain in :mod:basco.benchmarks.hera.

make_study

make_study(archive_root, state=None, *, model=None, gravity_degree=6, estimate_degrees=(2, 3, 4), parameterization='raw', higher_degree_bodies='both', prior='kaula', dt=75.0, duration=hera.DURATION_S, transport=None)

Installed, unpropagated Hera recipe. Supply the BASCO-owned reference directory and AC0-AC3, or a complete custom Hou BinaryDynamics through model=. These inputs are mutually exclusive. Defaults preserve the full paper setup. Custom geometry does not refit paper Kaula rules; choose a prior explicitly for a new scientific model. See the Hera customization guide for executable scripts and frame conventions.

Build one paper-style covariance study; no propagation occurs here.

Parameters

archive_root : path-like BASCO-owned reference/hera-20261016 directory. Paper moments and Kaula rules are checksum-verified; reference files are not edited. state : str or None AC0 equilibrium, AC1 libration, AC2 limited tumbling, or AC3 full tumbling. None selects AC3 when model is not supplied. Supplying both state and model is an error: a custom model owns its complete state. model : BinaryDynamics or None Explicit custom bodies, initial state, G and Hou gravity. When supplied, its gravity order must match gravity_degree. No orbit is recalibrated. gravity_degree : int Hou total mutual expansion order 2, 4 or 6, independent of solve-fors. estimate_degrees : tuple of int Distinct uncertain moment/harmonic degrees drawn from 2, 3 and 4. Both masses and the physical initial state are also estimated. parameterization : str raw selects mass-normalized moments; harmonics selects independent exterior coefficients for the requested degrees above degree two. higher_degree_bodies : str both, primary or secondary for the above-degree-two solve-fors. prior : str, iterable or None kaula reuses the paper's shape laws and independent raw-moment priors, including for a custom model. This is an explicit prior assumption, not a refit to a new shape. none/None removes priors; an iterable supplies custom prior producers. Mass and initial-state priors are not added. dt : float RK4 step in seconds; paper value 75. duration : float Analysis duration in seconds; default is the paper's full 16 orbits. transport : object or None None selects Hou AD. NativeAnalyticTransport selects analytic partials.

Returns

CovarianceStudy Unpropagated composable study with the four paper observation streams, 900 s cadence, the free barycenter and NuisanceProjectedSolver. Construct CovarianceStudy directly when replacing the observation model.
