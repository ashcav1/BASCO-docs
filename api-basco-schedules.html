basco.schedules

Composable observation schedules: which uniform-grid epochs are observed.

A schedule selects observation epochs; it never changes the dynamics or the transport output grid, so one propagation serves every schedule. Epochs are elapsed seconds since the study's initial state, plus the plan's schedule_offset. Windows are half-open [start, stop) intervals, and every boundary comparison allows BOUNDARY_TOLERANCE_S so exact grid instants are classified predictably.

Any object with mask(epochs) -> boolean array and describe() -> JSON-compatible dictionary is a schedule. Built-ins combine with &, | and ~.

Every

Import as basco.Every

Every(period: object, offset: object = 0.0)

Retain epochs separated by period seconds relative to offset, when they lie on the supplied base grid. It does not interpolate or create off-grid measurements.

Instants offset + n*period for integer n: a stream cadence on the base grid.

Every(2 * u.h) on a 15-minute grid observes one epoch in eight. The period should be a multiple of the plan cadence; other periods select only the grid epochs that happen to coincide with offset + n*period.

Import as basco.Periodic

Periodic(period: object, duration: object, phase: object = 0.0)

A periodic keep-window schedule on the existing epoch grid. period, duration and phase are in elapsed seconds.

Observed for duration out of every period: tracking passes or a duty cycle.

Periodic(24 * u.h, 8 * u.h) is one 8-hour pass per day starting at phase; Periodic(5 * u.min, 2 * u.min) is a 40 percent duty cycle.
