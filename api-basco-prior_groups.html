IndependentPriors

Import as basco.IndependentPriors

IndependentPriors(name: str, priors: object)

Compose independent prior producers while preserving each block metadata and its internal correlations. Independence between blocks is an assumption, not inferred from their names.

Combine independent blocks without discarding means, maps or correlations.

Each member retains its own whitening. Stacked pseudo-observations have dimensionless units and unit noise; no dense block covariance is needed. Duplicate information identities are rejected by resolve_priors.
