basco.history

Batch information histories and fixed-information uncertainty propagation.

These are two different time axes. covariance_history repeats the selected batch solve with all observations available by each cutoff, always estimating the same reference-epoch coordinates. propagate_covariance keeps one result's information fixed and maps its complete covariance through supplied Jacobians. Neither operation introduces process noise or performs sequential filtering.

covariance_history

Import as basco.covariance_history

covariance_history(data_rows, row_epochs, layout, noise, *, checkpoints=None, prior_rows=None, prior_descriptions=(), solver=None, parameters=None, diagnostics=None, rank_rtol=None, consider=None, reference_epoch_s=0.0)

Exact batch covariance prefixes, without repropagating dynamics.

data_rows are unwhitened derivatives in layout coordinates; row_epochs are their observation epochs in seconds. Checkpoints default to sorted distinct row epochs. All rows at a shared epoch enter together. Empty data default to one prior-only solve at reference_epoch_s.

Correlated noise is marginalized as R[I,I] for each prefix using ORIGINAL row identities. Slicing rows whitened using the complete dataset would leak information from future observations and is deliberately not supported. Custom noise operators must support explicit marginal subsetting.

The selected solver and its declared rank policy are called independently for each prefix. No QR compression, threshold adjustment or monotonicity assumption is applied. Consider uncertainty is never stacked as information. A solver requiring identifiable local coordinates can reject early prefixes; choose later checkpoints, or explicitly select SquareRootSolver for a history that includes unsupported early local directions. There is no automatic solver fallback.

propagate_covariance

Import as basco.propagate_covariance

propagate_covariance(result, epochs, jacobians, labels, units, *, values=None, information_cutoff_s, reference_epoch_s=None, conventions=None)

Map a FIXED result through explicit output Jacobians at physical epochs.

jacobians[k] maps the full reference-coordinate error to the requested output error at epochs[k]. It must include direct parameter dependence as well as transported state sensitivity. Every within-epoch cross term, including estimated/consider correlations, is retained by result.derived. The input result's null-aware support policy is also retained. If the result supplies a source square-root factor and derived_stable, mapping uses factor-first congruence rather than subtracting large terms in J P J.T. A custom result without this capability falls back to its own derived implementation; covariance validity is checked, but numerical stability cannot be inferred from a finite answer.

information_cutoff_s declares the last observation epoch used in that fixed result; it does not select measurements or add new information. The physical epochs may be before or after it. No process noise is introduced. If nominal output values are omitted, zeros denote error coordinates.
