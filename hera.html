Hera paper reproduction

The Hera analysis is BASCO's main scientific example. It estimates both masses and gravity-related moments through degree 4, propagating the nominal binary with Hou mutual gravity order 6. Four rotational states reproduce every one of the paper's 36 printed Table 2 percentages. This chapter gives the runnable entry points, the scientific choices behind them, and what the reproduction establishes.

For the shortest single-case script, a custom rotation of Dimorphos, or new system parameters, use Run and customize the Hera analysis.

Start with installation and first scripts if the environment is not set up. The example list has smaller demonstrations to try before a full propagation.

Run one case or all four

Run these from the repository root, after source tools/activate:

# Full tumbling, with tables and figures.
python examples/covariance/hera/paper_case.py

# All four paper cases, one after the other.
python examples/covariance/hera/all_cases.py

# The same in parallel processes, for chosen cases, with figures.
python tools/evidence/hera_all_cases.py AC1 AC3 --jobs 2 --figures

The one-case script is paper_case.py and the four-case script is all_cases.py. Both use the ordinary library components; neither contains a second covariance engine.

Timing depends on the machine and on what else it is doing: the recorded four cases each took 199 to 201 seconds with automatic differentiation, and about 25 minutes with the analytic partials. --jobs 1 of the evidence script reduces simultaneous load. A short run is not a reproduction of the paper: Table 2 needs the full 16 orbits and the stated settings.

USE_TEX = True at the top of paper_case.py draws the figure text with LaTeX, which must be installed. See results and plotting.

Runner configuration

This complete composition is the paper's default analysis, using the public components. ROOT below is the absolute BASCO checkout path; when writing a script inside examples/, use Path(__file__).resolve().parents[1] instead of hard-coding it.

from pathlib import Path

import numpy as np
import basco.covariance as bc
from basco.covariance.hera import hera

ROOT = Path("/absolute/path/to/BASCO")
REFERENCE = ROOT / "reference" / "hera-20261016"

# 1. Nominal bodies, rigid-body state and active Hou gravity order.
inputs = hera.load_inputs(REFERENCE)
model = hera.build_hera_model(inputs, "AC3", gravity_degree=6)

# 2. Uncertain physical coordinates and the initial-state tangent.
parameters = (
    bc.EstimatedParameters(model)
    .estimate_masses()
    .estimate_moments(degrees=(2, 3, 4))
    .estimate_initial_state()
)

# 3. Measurement streams and independently estimated barycenter.
observations = bc.ObservationSchedule.uniform(
    stop=hera.DURATION_S,
    cadence=900.0,
    observation_types=(
        bc.RelativePosition(sigma=1.0),
        bc.BodyAttitude("secondary", sigma=np.deg2rad(1.0)),
        bc.BodyAttitude("primary", sigma=np.deg2rad(1.0)),
        bc.PrimaryBarycentricPosition(
            sigma=1.0,
            nuisance=bc.PolynomialBias("barycenter", degree=1),
        ),
    ),
)

# 4. Prior knowledge, integration and numerical support policy.
analysis = bc.CovarianceAnalysis(
    model,
    parameters,
    observations,
    integrator=bc.RK4(dt=75.0),
    priors=(hera.HeraKaulaPrior(parameters, REFERENCE),),
    solver=bc.PartitionedSquareRootSolver(),
)

# 5. Propagate once, analyze, then present without new dynamics.
design = analysis.design_matrix()
result = design.covariance()
paper = hera.hera_report(result)
print(paper.summary())

folder = bc.export_analysis(design,
    result,
    ROOT / "results",
    label="hera-full-tumbling-g06-e04",
    reports={
        "paper": paper,
        "harmonics": result.harmonics(),
        "mass": result.mass_properties(),
    },
    figures=True,
    theme=bc.PlotTheme(tex=False),
)
print(folder)

Each numbered part has one owner. BinaryModel describes the physics; EstimatedParameters selects independent uncertainty coordinates; ObservationSchedule describes the measurements; HeraKaulaPrior produces ordinary prior rows; PartitionedSquareRootSolver owns numerical elimination; export_analysis owns standardized output. The derivative provider is another component: add partials="analytic" to the analysis for analytic partials, keeping everything else identical.

The factory make_analysis in the actual runner exposes state, gravity_degree, estimate_degrees, parameterization, higher_degree_bodies, prior, dt, duration and transport. It is an example function, not a hidden global setting or a second public package API.

Didymos barycentric position measurement

The final paper includes Didymos' position relative to the system center of mass. Its model is

\boldsymbol y_A(t) =
-\frac{M_B}{M_A+M_B}\,C_{NA}(t)\boldsymbol r_A(t)
+\boldsymbol R_0+(t-t_\mathrm{ref})\boldsymbol V_0.

PrimaryBarycentricPosition includes the direct mass-ratio derivative and the mass dependence carried through the trajectory. The PolynomialBias adds the six free position/rate coordinates. Dropping this observation type changes the experiment. Keeping the observation type but dropping its nuisance model assumes a known barycenter and also changes the experiment.

The four streams contribute three scalar components each: inertial relative position, secondary attitude tangent, primary attitude tangent, and primary barycentric position. Position noise is 1 m per component; attitude noise is 1° per component, expressed internally in radians. These attitude directions support formal covariance; general measured-attitude residual ingestion remains separate work.

Kaula prior constraints

The paper configuration combines two independent information components: 36 harmonic rows and 56 raw-moment rows. It does not add a mass prior. HeraKaulaPrior binds the reusable KaulaPrior and archived, checksum-verified laws to the selected layout.

The paper's plotted harmonic prior uncertainty is the original Kaula envelope. The normalized polar-moment prior is taken from the captured round-20 prior record, in units of Izz/(M R²). These are distinct reported quantities. Figure 3 comes from refitting the archived coefficient clouds; it does not imply that every original random mesh was regenerated. See shapes and Kaula for newly sampled ensembles.

Degree, prior and gravity trades

Use separate choices rather than changing a kernel:

# Inside a script with make_analysis from examples/hera_covariance.py:
degree2 = make_analysis("AC3", estimate_degrees=(2,), prior="none")

# The paper's expanded no-prior case: primary-only higher harmonics.
primary_high = make_analysis(
    "AC3",
    estimate_degrees=(2, 3, 4),
    parameterization="harmonics",
    higher_degree_bodies="primary",
    prior="none",
)

paper_baseline = make_analysis("AC3")
gravity4 = make_analysis("AC3", gravity_degree=4)

The second Figure 5 group estimates both bodies' degree-2 inertia coordinates and masses, plus primary-only exterior degree-3/4 harmonics. It is not the same as both-body raw degree-4 moments without a prior. The latter retains structural trace null directions; its unavailable uncertainties must remain unavailable.

degree_trades.py makes these comparisons from one design matrix. The evidence script tools/evidence/hera_degree_trades.py separates the two steps: propagate makes a new variational solution, and compare verifies and reuses completed ones without more propagation. The recorded comparison used the analytic partials, so its compare defaults to --derivatives native (the earlier word for them), while a fresh propagate defaults to AD. A variational solution computed with one is refused for an analysis that names the other.

Figure 5's reproduced no-prior sigma errors are 2.5417e-6 for degree 2 and 3.8168e-6 for the primary-only higher-degree experiment. The four prior cases pass the same Table 2 checks. Degree-trade evidence records the exact scientific configuration.

The six groups compare the two no-prior experiments with the four Kaula-prior rotational cases. The legend includes both estimated masses. Izz denotes the normalized polar moment used in the paper's percentage reports.

Changing gravity order requires a new trajectory. Changing only compatible priors/noise can reuse rows. Reducing the uncertain coordinate subset can reuse validated variational solution through the corresponding map; it conditions omitted estimated parameters as fixed. The workflow chapter explains reuse boundaries.

An order-4/order-6 ratio compares two model-conditioned covariances. It does not measure parameter bias from omitted gravity or prove that the model with smaller formal errors is more accurate.

Fresh propagation, row replay and saved results

Operation What it establishes Additional dynamics
Fresh CovarianceAnalysis.design_matrix() BASCO's variational solution, observation assembly, priors and solver reproduce the configured experiment Yes
hera.load_hera_archive(...) Archived PyGUBAS rows, transformed into physical SI coordinates, agree under BASCO covariance/report algebra No
hera.load_saved_variational_solution(...) A checked completed BASCO trajectory supports a compatible new estimated parameter/measurement analysis No
read_results(folder) or presentation rendering A saved result is checksum-valid and can be read/reformatted No

Replay converts native kilometers, fractional moment/GM columns and centered Legendre barycenter coefficients into SI mass, moment, R0 and V0 coordinates. It is valuable independent evidence of conversions and algebra, but it cannot validate fresh dynamics on its own.

Output files

The one-case export contains the paper, harmonics and mass report families, numeric arrays, layouts/units, configuration/provenance, checksums and optional figures. Standard run names include a descriptive label, UTC timestamp and analysis fingerprint. See results for the full directory contract.

saved = bc.read_results(folder)  # Verifies the completed standard run.
print(result.mass_properties().summary())  # Both masses, total, GMs and ratio.
print(hera.hera_report(result).summary())  # Exact paper conventions.

Never label a prior/noise/degree variant as the paper baseline without recording its changes. The saved configuration and provider identity are the evidence, not the folder's informal nickname.

Limits of the reproduction

These are formal local uncertainties around a nominal rigid-body model. They do not constitute a fit to actual Hera observations, a nonlinear uncertainty-validity proof over chaotic arcs, or a new integration-step convergence analysis. Complete end-to-end finite-difference coverage of the covariance chain is still open.

Round 20 supplies Table 2's baseline. Six same-dynamics round-21 prior/noise/baseline variants have been checked; 13 other round-21 trajectory/basis variants remain unverified. In particular, one archived position-noise sweep holds the barycentric noise fixed while later paper plotting ties it to relative-position noise. Baseline 1 m results coincide; other points need the matching reanalysis.
