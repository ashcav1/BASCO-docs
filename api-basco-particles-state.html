Particle

Import as basco.particles.Particle

Particle(name: str, position: object, velocity: object, area_to_mass: object = 0.0, reflectivity: float = 1.0)

A named test particle in inertial binary-barycentric SI coordinates.

area_to_mass is projected m²/kg; reflectivity is the cannonball SRP factor. Neither gives the particle gravitational backreaction. Epoch is supplied to propagate_particles and must also identify the binary initial state.

ParticleTrajectory

Import as basco.particles.ParticleTrajectory

ParticleTrajectory(epochs: object, binary_states: object, particle_states: object, particles: tuple, outcomes: tuple, model: object, metadata: dict)

One common binary history and nominal SI histories for independent particles.

Terminated particles contain NaN after their event, never a fabricated rest trajectory. Event epochs are included alongside requested regular outputs. completed means only that the requested horizon was reached.
