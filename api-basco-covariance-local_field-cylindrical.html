basco.covariance.local_field.cylindrical

Cylindrical harmonics: solutions of Laplace's equation inside a cylinder.

In cylinder coordinates scaled by a length (X, Y along the base, Z along the axis), with t = X^2 + Y^2, each function is

phi_mn = exp(-k Z) Q_m(X, Y) 0F1(m + 1; -k^2 t / 4)

Q_m is the real or the imaginary part of (X + iY)^m, and k is a positive wavenumber. This is exp(-k Z) J_m(k sqrt(t)) cos(m phi) or sin(m phi), with J_m the Bessel function, written so that it is well behaved on the axis. The potential is U = sum of b_mn phi_mn [m^2/s^2] and the acceleration is minus its gradient. The coefficients b_mn are the parameters of the local field.

The form follows Fereoli et al., Celestial Mechanics and Dynamical Astronomy (2026), doi:10.1007/s10569-026-10281-7, Eq. 36. The derivatives are available from closed-form expressions ("analytic") and from automatic differentiation ("ad").

CylindricalHarmonics

Import as basco.covariance.local_field.CylindricalHarmonics

CylindricalHarmonics(patch: CylindricalDomain, azimuthal_degree: int = 2, radial_order: int = 3, radial_scale: object = None, prefix: str = 'nearfield', coefficient_scales: object = field(default=None, repr=False))

Named, axis-regular, one-sided decaying Fourier–Bessel modes in a fixed mass-free patch. Coefficients are normalized potential amplitudes in m²/s², not raw Bessel coefficients or density parameters. The zero sine mode at m=0 is excluded. Current supported numerical envelope is m≤12, radial order≤12 and full-patch Bessel argument≤4. Scales improve conditioning and supply no statistical information.

A set of cylindrical harmonics in one cylinder.

patch: the CylindricalDomain. azimuthal_degree: highest m. radial_order: number of radial functions per m. radial_scale: the length that makes the coordinates dimensionless [m]. prefix: start of the coefficient names. coefficient_scales: typical sizes of the coefficients.

modes lists the functions and layout names their coefficients.

design(self, points, *, quantity='acceleration', backend='analytic')

Linear coefficient-to-field operator at checked body-frame points. Potential returns (N,n_coefficient); acceleration returns (N,3,n_coefficient). The default native operator uses independent analytic spatial derivatives without loading JAX; backend='ad' differentiates the separate Cartesian series.

The matrix that turns coefficients into the field at points: potential (N, size) or acceleration (N, 3, size), in the body's frame. The field is linear in the coefficients.

LocalFieldEvaluation

LocalFieldEvaluation(potential: float, acceleration: object, position_jacobian: object, potential_jacobian: object, coefficient_jacobian: object)

Immutable single-point field result in body-frame SI. Coefficient derivatives and position derivatives are separate so a user can compose their shared source pathways before forming covariance.

A local field at one point, in the body's frame.

potential [m^2/s^2], acceleration (3,) [m/s^2], position_jacobian (3, 3) = d acceleration / d position, potential_jacobian and coefficient_jacobian = d potential / d coefficients and d acceleration / d coefficients.

CylindricalHarmonicField

Import as basco.covariance.local_field.CylindricalHarmonicField

CylindricalHarmonicField(basis: CylindricalHarmonics, coefficients: object, backend: str = 'ad')

A local nominal potential and acceleration model. AD is default and lazy; backend='native' selects independent analytic Cartesian derivatives. The field has no built-in covariance or constant-density assumption and can be selected explicitly as a per-body particle field in RF3BPDynamics. BASCO uses a=-grad(U) with negative gravitational potential.

A gravity field made of cylindrical harmonics with given coefficients.

basis: the CylindricalHarmonics. coefficients: one value per function. backend: "ad" or "analytic".
