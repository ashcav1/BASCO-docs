basco.consider

Fixed-estimator consider covariance, independent of dynamics and observations.

For whitened data and prior equations A dx + B dc = noise, only dx is fitted. The external consider error dc = true - fixed has covariance C and is independent of the equation errors. The estimated error uses the same truth-minus-estimate convention, giving S = -A^+ B and P_x = P_conditional + S C S.T. This is batch covariance analysis, not a recursive Schmidt filter or a posterior update of the consider distribution.

An external, possibly correlated PSD uncertainty on named coordinates.

covariance[i, j] has units units[i] * units[j]. Units must match the source layout exactly: no implicit conversion or diagonal-only approximation is performed. Zero uncertainty and singular covariance are allowed. The covariance is copied and never updated by observations. Accepted roundoff-scale asymmetry or negative correlation eigenvalues are canonicalized to a symmetric PSD covariance, with the correction recorded in normalization. Propagation uses factor to avoid negative variances from subtraction near a singular distribution.

ConsiderParameters.from_priors

from_priors(cls, priors, layout, nominal, *, labels, name='consider', source='prior-derived external covariance', solver=None)

Convert self-contained, centered prior rows into an external C.

Ordinary prior producers are resolved on the full source layout and nominal. Whitened equations touching the requested coordinates must have no columns outside that selection and no nonzero mean-minus-reference residual. Their prior-only covariance must be full rank. Harmonic maps and independent raw-moment prior rows can therefore be combined without hand inversion or unit conversion.

This operation neither conditions nor marginalizes a coupled joint prior. Supply the desired marginal Gaussian prior explicitly when that is the intended distribution. These rows define external consider uncertainty; remove corresponding rows from estimator priors before fitting or covariance analysis. No observation data update the distribution returned here.

ConsiderResult.map_factor

map_factor(self, jacobian)

Return [Jx Fconditional, (Jx S + Jc) Lconsider] with the same latent columns as supported_subspace_factor. Combining fitted-response and direct consider dependence before applying the external factor preserves cancellation. The external distribution, estimated rank and conditional nullspace remain unchanged; a finite mapped row does not establish observability.

Map conditional and consider latent errors with direct cancellation.

Return [Jx @ F_conditional, (Jx @ S + Jc) @ L_consider] in the exact latent-column order of supported_subspace_factor. Forming the consider transfer before applying its original factor preserves cancellation between fitted response and direct physical dependence. No covariance is factored, and no consider distribution is updated.

jacobian must be finite, two-dimensional and contain all source coordinate columns. The finite readonly output describes supported errors only; callers must preserve the original conditional nullspace and report/status policy. It does not make unidentified directions finite. Existing derived/report arithmetic remains unchanged.

analyze_consider

Import as basco.analyze_consider

analyze_consider(whitened_rows, layout, consider, *, prior_rows=None, prior_descriptions=(), solver=None, parameters=None, diagnostics=None, rank_rtol=None)

Partition full-source whitened rows into estimated and consider columns.

Data and prior rows retain both column blocks. The external consider covariance is not stacked as a prior, updated, or used in the estimator gain. Equation noise and prior-equation errors are mutually independent and independent of the consider error. A joint stochastic prior that violates this independence requires a different treatment and is outside this contract.

The selected covariance solver determines conditional numerical support. Rank-deficient custom solvers must also implement solve_correction so their selected generalized-inverse convention is retained.
