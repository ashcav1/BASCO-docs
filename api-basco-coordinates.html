Parameters.estimate_harmonics

estimate_harmonics(self, bodies='both', degrees=(3, 4))

Select independent unnormalized exterior C/S coordinates for degree 3 and/or 4 with a fixed trace-complement gauge. Degree 2 uses estimate_moments so the extra inertia direction is retained. Raw and harmonic choices cannot overlap at the same body and degree.

Independent unnormalized C/S coefficients, with fixed trace complement.

Degree2 remains diagonal moments because rotation also needs its third inertia coordinate. Higher-degree raw mode remains available and retains all exterior-gravity trace null directions.
