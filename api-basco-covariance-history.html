basco.covariance.history

Uncertainty over time, in two different senses.

covariance_history: how the covariance improves as observations accumulate. The analysis is repeated with the observations up to each checkpoint. The unknowns are always the same ones, referred to the initial time.

map_covariance: one finished result, mapped to quantities at other times. The information is fixed; only the quantity that is reported changes with time.

Neither is a sequential filter and neither adds process noise.

covariance_history

Import as basco.covariance.covariance_history

covariance_history(data_rows, row_epochs, layout, noise, *, checkpoints=None, prior_rows=None, prior_descriptions=(), solver=None, parameters=None, diagnostics=None, rank_rtol=None, consider=None, reference_epoch_s=0.0)

The covariance at each checkpoint, from the observation rows up to it.

data_rows: unwhitened design matrix rows. row_epochs: the epoch of each row [s]. checkpoints: times [s]; every distinct observation epoch by default. Choose fewer to save time: each checkpoint is one complete analysis. noise: the noise of all rows. For each checkpoint the noise of its rows alone is used (subset_noise). Whitening with the noise of the complete data set and then cutting rows would let later observations influence earlier results when the noise is correlated. consider: ConsiderParameters, for a consider analysis at every checkpoint.

The solver is applied afresh at each checkpoint. Early checkpoints can have too few observations for the PartitionedSquareRootSolver; use later checkpoints or the standard solver for those.

map_covariance

Import as basco.covariance.map_covariance

map_covariance(result, epochs, jacobians, labels, units, *, values=None, information_cutoff_s, reference_epoch_s=None, conventions=None, mapped_factors=None)

Map one fixed source result at physical epochs without observations or process noise. Optional mapped_factors supplies already transported original-latent factors when forming the earlier-source Jacobian first loses precision. Covariance is formed from those factors, while the original full-source Jacobians retain all null/support decisions. Existing generic derived/report arithmetic is unchanged.

Map one result to quantities at a list of epochs: a MappedCovarianceHistory.

jacobians: (n, q, unknowns); jacobians[k] holds the partials of the quantities at epochs[k] with respect to the unknowns of result, including any direct dependence on the parameters. information_cutoff_s: the time of the last observation used in result. It is recorded with the output; it selects nothing. values: nominal values of the quantities (zeros when not given). mapped_factors: (n, q, columns) optional: the factor J F computed by the caller, for when assembling J first would lose accuracy.

The covariance at each epoch is J P J^T, computed from the covariance factor when the result offers one. Quantities that depend on undetermined directions get NaN.
