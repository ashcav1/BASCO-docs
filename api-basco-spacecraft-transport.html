SpacecraftTrajectory

Import as basco.spacecraft.SpacecraftTrajectory

SpacecraftTrajectory(epochs: object, states: object, state_transition: object, raw_sensitivities: object, parameters: object, reference_epoch_s: float, identity: TransportIdentity, diagnostics: dict, initialization: object = None)

Readonly RF3BP nominal/variational history at physical elapsed epochs.

states stores native30 binary followed by spacecraft inertial SI6. state_transition differentiates those 36 stored initial coordinates; raw_sensitivities differentiates mass-weighted SI moments in parameters' raw_slots order. reference_epoch_s names original source coordinates; release_epoch_s names the integration start. initialization retains J0. identity records physical/numerical settings; diagnostics includes sampled domain and integration settings, without claiming continuous contact detection.

SpacecraftTrajectory.covariance

covariance(self, uncertainty, *, ignored_labels=())

Maps original source factors through initialization and raw-parameter maps before subsequent variational transport, reducing precision loss from long-arc cancellation. Full-source Jacobians still govern null support. Original latent columns, consider cancellation and correlations are retained. Unknown labels, incompatible physical maps/units and epoch mismatches fail explicitly.

Return spacecraft position/velocity covariance, adding no observations.

uncertainty is SourceUncertainty (supplied or retaining an existing covariance/consider result) at this trajectory's reference epoch. Its source factor/null policy and information cutoff remain unchanged. The output is the existing DerivedCovarianceHistory and uses existing exports/plot recipes; measurement noise and process noise are absent.

propagate_spacecraft

Import as basco.spacecraft.propagate_spacecraft

propagate_spacecraft(dynamics, initial, *, duration, cadence=60.0, integrator=None, reference_epoch_s=None, handoff=None)

Propagate RF3BP nominal state/STM/raw sensitivities with shared RK4 stages.

dynamics is RestrictedDynamics; initial is inertial SpacecraftState or BodyFixedRelease. Optional handoff is BinaryHandoff.from_transport; its retained native state is used without projection, and J0 preserves original source-coordinate sensitivities. Otherwise the supplied model is initial. duration/cadence are positive seconds, duration an integer number of output cadences; RK4 dt must divide cadence. reference_epoch_s labels original source coordinates (default 0, or handoff.reference_epoch_s). Output epochs start at handoff.epoch_s when supplied. Relabeling an epoch never advances a nominal state. This routine generates no measurements or estimation.
