SpacecraftTrajectory

Import as basco.spacecraft.SpacecraftTrajectory

SpacecraftTrajectory(epochs: object, states: object, state_transition: object, raw_sensitivities: object, parameters: object, reference_epoch_s: float, identity: TransportIdentity, diagnostics: dict)

Readonly RF3BP nominal/variational history at physical elapsed epochs.

states stores native30 binary followed by spacecraft inertial SI6. state_transition differentiates those 36 stored initial coordinates; raw_sensitivities differentiates mass-weighted SI moments in parameters' raw_slots order. reference_epoch_s is the initial/source epoch. identity records physical/numerical settings; diagnostics includes sampled domain and integration settings, without claiming continuous contact detection.

SpacecraftTrajectory.source_jacobians

source_jacobians(self, layout, *, ignored_labels=())

Map named same-epoch source errors to every combined stored state.

Missing known coordinates are held fixed. Unknown coordinates fail unless explicitly listed in ignored_labels (for example observation nuisance coordinates irrelevant to barycentric spacecraft dynamics). Ignoring a recognized physical coordinate is rejected. This slice maps inertial spacecraft initial errors, not a body-fixed release or a covariance referenced to a different initial epoch.

SpacecraftTrajectory.covariance

covariance(self, uncertainty, *, ignored_labels=())

Maps named same-epoch physical source errors through initial-state and raw-parameter sensitivities into six-output position/velocity covariance histories. Source factors, consider cancellation and null support are retained. Unknown labels, incompatible physical maps/units and epoch mismatches fail explicitly.

Return spacecraft position/velocity covariance, adding no observations.

uncertainty is SourceUncertainty (supplied or retaining an existing covariance/consider result) at this trajectory's reference epoch. Its source factor/null policy and information cutoff remain unchanged. The output is the existing DerivedCovarianceHistory and uses existing exports/plot recipes; measurement noise and process noise are absent.

propagate_spacecraft

Import as basco.spacecraft.propagate_spacecraft

propagate_spacecraft(dynamics, initial, *, duration, cadence=60.0, integrator=None, reference_epoch_s=0.0)

Propagate RF3BP nominal state/STM/raw sensitivities with shared RK4 stages.

dynamics is RestrictedDynamics; initial is inertial SpacecraftState. duration/cadence are positive seconds, duration an integer number of output cadences; RK4 dt must divide cadence. reference_epoch_s is an elapsed-second origin used by both initial source errors and output epochs. It does not move the supplied nominal binary to a different physical epoch.
