basco.common.output

Writing result files safely: folders that appear only when complete, checksums, JSON, CSV.

A result folder is first written under a temporary name next to its destination and renamed when everything is in it. A list of the files with their SHA-256 checksums (a manifest) lets a reader verify that nothing was changed or lost.
