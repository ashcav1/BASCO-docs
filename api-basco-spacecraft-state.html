SpacecraftState

Import as basco.spacecraft.SpacecraftState

SpacecraftState(position: object, velocity: object)

Six inertial Cartesian values relative to the binary barycenter. Initial uncertainty is a separate SourceUncertainty. This state has no mass or attitude and cannot feed back into the binary.

Six Cartesian coordinates in the inertial binary-barycentric frame.

position is a three-vector in metres; velocity is a three-vector in m/s. Astropy quantities are accepted and converted at this boundary. The epoch belongs to the trajectory/source uncertainty, not to the numeric state. This state has no mass, spin, attitude or effect on the binary dynamics.
