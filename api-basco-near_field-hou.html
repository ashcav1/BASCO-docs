basco.near_field.hou

Exterior Hou samples in named physical parameter coordinates.

This adapter is intentionally independent of cylindrical harmonics and the spacecraft integrator. A local basis is supplied only to map_to. Sampling inside the source enclosing sphere is forbidden; fitting outside that sphere does not establish the physical accuracy of continuation below it.

FieldSamples

FieldSamples(points: object, values: object, jacobian: object, layout: CoordinateLayout, identity: object)

HouFieldSource

Import as basco.near_field.HouFieldSource

HouFieldSource(parameters: object, body: str, enclosing_radius: object = None, backend: str = 'ad')

Samples one body's intrinsic exterior Hou acceleration in its own COM/body frame. The adapter applies the existing raw-moment-to-physical chain rule exactly once, retains all physical columns, and includes nominal degree-5/6 mass response. Samples must lie outside the known enclosing sphere. AD is default; native derivatives remain explicit.

Sample one body's exterior field without losing physical mass pathways.

Parameters

parameters : Parameters or ResolvedParameters Existing physical solve-for map, including any uncertain mass, raw normalized moments or independent exterior harmonics. All columns are retained, including the other body's zero local-field columns. body : {"A", "B"} Body whose own COM/principal-axis frame contains the sample points. enclosing_radius : float or Quantity, optional Known enclosing radius in metres. Defaults to the body's distribution bound; an override may only enlarge that bound. backend : {"ad", "native"} Same explicit derivative selection as HouBodyField. AD is default.

sample uses raw mass-weighted moment partials multiplied by the existing resolved physical Jacobian exactly once. values reevaluates the complete physical map, including degree5/6 mass response when only degrees2–4 are independent. Neither method makes estimation rows.

HouFieldSource.map_to

map_to(self, basis, points, *, completion, row_scales=None, rcond=None)

Fit a supplied local linear basis to valid exterior acceleration samples and their physical source derivatives. A nonempty completion assumption is required. The fit changes representation but adds no measurement information; residuals are approximation diagnostics rather than coefficient covariance.

Fit nominal coefficients and the same deterministic source transfer.

completion must describe the assumed continuation. Fit residuals diagnose representation error; they are not coefficient covariance. The returned generic map can bind an existing covariance result or a provided joint SourceUncertainty without rebuilding its factor.
