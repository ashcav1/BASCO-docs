PhysicalReportMaps

PhysicalReportMaps(parameters: object)

Bind binary report functions to their resolved physical coordinates.

The covariance result calls this service only when a physical report is requested. Custom parameter contexts can supply another callable with the same (name, layout, *args) interface without changing either solver.

mass_properties_map

mass_properties_map(parameters, layout)

Values and joint-coordinate Jacobian for masses and fixed-G reports.

The mass ratio is secondary/primary, M_B/M_A. G is a fixed physical constant from the resolved model, never another independent coordinate. Missing mass coordinates are fixed; this map contributes no information.
