basco.dynamics.ad

The equations of motion of the binary written with JAX, and their partials by automatic differentiation (AD). This is the default way BASCO gets its partials.

The package is a copy, function by function, of the gravity and the equations of motion of the GUBAS C++ code (native/legacy/gubas_core.cpp), written so that JAX can differentiate it:

hou_tables.py                the coefficients of Hou's series (plain NumPy)
gravity.py                   the mutual potential U
dynamics.py                  the equations of motion F; forces and torques are
                             derivatives of U
partials.py                  A = dF/dx and B = dF/dT, by differentiating F
variational_equations.py     ADVariationalEquations, which integrates them
conservation.py              energy and angular momentum, for checking

No hand-derived partial is used anywhere in this package. The legacy analytic code is kept separately and is chosen with partials="analytic".

Another gravity model only needs its potential energy: any object with mutual_order and a method potential(r, C_AB, T_A, T_B, G) in SI units can replace HouGravity in a BinaryModel, and everything else follows by differentiation. SecondDegreeGravity (gravity.py) is the smallest example; MasconGravity (mascon.py) is another.

JAX is needed only when something is propagated (the basco[ad] extra). Importing this package or building a CovarianceAnalysis does not load it.
