BinaryState

Import as basco.BinaryState

BinaryState(position: object, velocity: object, omega_primary: object, omega_secondary: object, A_to_N: object, B_to_A: object)

Position and inertial velocity are relative-secondary-to-primary vectors expressed in primary-body components. Velocity is not d(position_in_primary_frame)/dt. Both inertial spin vectors are also expressed in primary components. A_to_N maps primary components to inertial components; B_to_A maps secondary components to primary components. Public lengths are metres, rates radians/s, and rotation matrices dimensionless.

Inertial r/velocity and both inertial spin rates, resolved in A.

A_to_N maps primary components into inertial components; B_to_A maps secondary components into primary components. Velocity is not dr_A/dt.

BinaryState.from_native

from_native(cls, native, *, project=False)

Use project=True only when explicitly turning a propagated RK4 state into a new physical initial state; this projects each approximate rotation onto SO(3). Ordinary dynamics output is not silently projected.

Inverse of to_native; project=True maps each DCM to its nearest rotation.

Fixed-step RK4 preserves orthogonality only to its truncation error, so a propagated state reused as an initial state needs the projection (polar decomposition by SVD). Without it, non-rotations are rejected.
