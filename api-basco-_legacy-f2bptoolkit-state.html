InitialState

InitialState()

State vector for the F2BP.

The 30-element state vector is: [r(3), v(3), omega_c(3), omega_s(3), A_to_N(9), B_to_A(9)]

where r : relative position of secondary in primary body frame (A), km v : relative velocity in A frame, km/s omega_c : primary angular velocity in A frame, rad/s omega_s : secondary angular velocity in the PRIMARY body frame (A), rad/s. This is the secondary's INERTIAL angular velocity expressed in A -- not its rate relative to A, and not a B-frame quantity.

        An earlier version of this docstring claimed the B frame. That
        was wrong, and it matters when you SET the state: whatever you
        pass to ``omega_secondary`` goes straight into x[9:12], which
        the C++ reads as an A-frame inertial rate. The two readings
        coincide only when B_to_A is the identity -- which is the
        default, which is why the error went unnoticed. If you set a
        non-identity B_to_A, you must supply omega_s in A.

A_to_N : rotation matrix A→N (Cc in Hou notation), row-major (9 elements) B_to_A : rotation matrix B→A (C in Hou notation), row-major (9 elements)

The Python API works in SI (meters, m/s). Conversion to C++ internal units (km, km/s) is done by to_vector_km().
