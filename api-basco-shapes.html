basco.shapes

Shape geometry, signed volume moments, and reproducible shape perturbations.

All geometry is in metres. Surface winding is checked before integrating signed tetrahedra; taking absolute tetrahedron volumes would corrupt concave meshes. The retained GUBAS scientific implementation owns the moment algebra.

to_distribution(self, mass_kg, *, max_degree=6, reference_radius_m=None, alignment_tolerance=1e-10)

Align to center of mass/principal axes, integrate mass-weighted moments, check structural roundoff, and produce a Hou-ready MomentDistribution. The fixed harmonic radius and enclosing bounding radius have distinct meanings.

Build a mass-weighted principal-axis MomentDistribution for propagation.

Aligns the mesh, checks residual first/product moments relative to M*R**degree, and sets only those structural roundoff residues to zero. Raises instead of discarding a residual above alignment_tolerance. The bounding radius is computed separately from the reference radius.

RadialShapeSampler

RadialShapeSampler(roughness_m: float, correlation_lengths_m: tuple, copies_per_length: int = 50, seed: int = 0, stream: int = 0, legacy_integer_length_seed: bool = False)

Seeded radial shape perturbations with requested RMS roughness and correlation lengths in metres. Choose sample count, resolution, frame/realignment and legacy seed convention explicitly for a science campaign.

Seeded Gaussian spherical-harmonic radial roughness (degrees 0/1 removed).

Correlation length sets L=max(2,round(pi*R/length)); each field is rescaled to roughness_m RMS on the sampled vertices, as in the retained recipe. legacy_integer_length_seed=True reproduces the paper's integer-length seed convention; the default preserves every bit of the requested length.
