basco.spacecraft.contact

First inward surface events and original-factor contact covariance.

The driver reuses the shared augmented RK4 step. It retains each valid endpoint, limits inward steps using the current signed gap/rate, and refines resolved sign brackets from the same augmented left endpoint. One-sided termination uses explicit spatial and estimated-time residual tolerances; no force is silently extended across an invalid field domain. A finite horizon with no event is not a proof of escape, and sampled intervals are not an unconditional first-root certificate for arbitrary oscillatory trajectories or tangencies.

integrate_to_contact

Import as basco.spacecraft.integrate_to_contact

integrate_to_contact(evaluate, initial, n_parameters, event, duration, dt, cadence, *, distance_tolerance_m=1e-08, time_tolerance_s=1e-07, domain_errors=(), max_steps=100000, normal_speed_tolerance=1e-10, relative_grazing_tolerance=1e-07)

Use the shared augmented RK4 step for state, STM and parameter sensitivities. Event value is a positive-outside distance and event.rate is exact normal speed. Inward gap/rate limiting and one-sided residual/time criteria avoid silently extending a force below its accepted domain. Explicit outcomes include contact, no_contact within horizon, domain_exit, grazing, edge, initial_inside/contact and numerical_failure. Chronological resolved steps are not an unconditional arbitrary-root certificate.

Propagate state/STM/parameter sensitivities to a first resolved inward event.

evaluate(state) returns F,A,B in declared coordinates. event(state) returns a positive-outside gap in metres, and event.rate(state,F) its exact normal speed in m/s. An optional event.sample(state) returns a surface sample with smooth; optional event.speed(state,F) supplies a physical total point speed for a relative grazing threshold.

domain_errors names only explicit field-domain exceptions; other model errors propagate. A rejected RK trial is retried at half its step without changing the retained left state. The diagnostics expose rejected trials, residuals and the resolution policy. Contact coordinates are the limiting integrated state within declared tolerance, never a clipped/projected force state. Numerical refinement must be checked against the application's scale.

contact_covariance

Import as basco.spacecraft.contact_covariance

contact_covariance(source, position, body_velocity, normal, position_jacobian, position_factor, *, epoch_s, conventions=None, normal_speed_tolerance=1e-10, relative_grazing_tolerance=1e-07)

Correct fixed-time target-body position derivatives for uncertain event time: t_q=-n*J/(n*v), J_contact=J+v*t_q. Apply the same operation to original transported latent columns, retaining full-J source support and consider/null conventions. Requires a smooth inward event and nonzero normal speed; no covariance is manufactured for grazing or unavailable directions.

Correct a fixed-time body-position map for uncertain first-contact time.

Inputs use body-frame metres/metres-per-second and original physical source columns. position_factor must retain the original latent columns from transport. Full Jacobians remain authoritative for support; factors supply cancellation-aware covariance. No source covariance is reconstructed.
