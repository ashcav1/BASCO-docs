basco.particles.plots.drawing

Shared drawing functions for figures with many trajectories.

Hundreds of trajectories need different choices from a handful:

  • Colour shows one continuous variable on a shared colour scale, never one colour per trajectory.
  • Line style and end marker show the outcome, in dark grey in the legend.
  • Line width and opacity shrink with the number of trajectories, so bundles stay readable.
  • Parts of a trajectory behind a body are drawn thin and faint, using a depth map.
  • A panel draws at most MAX_LINE_SAMPLES line samples. Trajectories are drawn as lines up to the time that fits that limit; after it, the residence time of the particles is shaded.
  • Line collections are rasterized, so vector pages stay small.
