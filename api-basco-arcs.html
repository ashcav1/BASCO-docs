basco.arcs

Independent arcs on one continuous nominal trajectory.

ArcTimeline cuts a mission into contiguous arcs. MultiArcCovarianceStudy builds one ordinary CovarianceStudy per arc: arc k+1 starts at arc k's final nominal state, so the arcs follow one continuous trajectory, while every arc estimates its own initial binary state. Masses and gravity are shared; the existing MultiArcStudy owns all statistics. Observation schedules are evaluated in mission time, so a daily blackout stays daily across arc boundaries.

MultiArcCovarianceStudy

Import as basco.MultiArcCovarianceStudy

MultiArcCovarianceStudy(model, parameters, observations, timeline, integrator=None, *, transport=None, priors=(), arc_priors=None, shared_parameters=None, solver=None)

High-level binary multi-arc covariance: one continuous nominal, independent local initial-state errors per arc, shared masses/gravity, and optional arc-local nuisance. Shared priors enter once. There is no implicit continuity constraint.

Independent arcs: re-estimate the binary state per arc, share the physics.

Example: arcs = bc.ArcTimeline.every(3.5 * u.day, stop=14 * u.day) study = bc.MultiArcCovarianceStudy(model, parameters, plan, arcs, bc.RK4(75)) result = study.linearize().covariance()

observations is the mission plan: its cadence, channels and schedules apply to every arc, with schedules evaluated in mission time. Arc 0 starts at the model's initial state; arc k+1 starts at arc k's final propagated state, projected onto SO(3). priors (shared knowledge) enter once; arc_priors(arc, parameters) may return local priors for one arc. Any transport provider and solver can be selected, exactly as for CovarianceStudy.
