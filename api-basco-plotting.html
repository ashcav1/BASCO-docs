basco.plotting

Optional Matplotlib renderer of canonical presentation data.

No dynamics, uncertainty calculations, or global pyplot state live here. Every figure uses PlotTheme and exports the same PNG/SVG/PDF views.

uncertainty_comparison_plot

uncertainty_comparison_plot(cases, *, table='harmonics', metric='sigma', labels=None, reference=None, identifier='uncertainty_comparison', title=None, group_labels=None, panel_by_group=True, value_labels=False, layout=None, parameter_labels=None)

Build a replaceable grouped-bar figure from canonical presentations.

cases is an ordered mapping of display names to PresentationDataset. metric selects sigma, relative_percent, or gain. Gain requires a separate reference presentation, typically a prior-only covariance. Filtering uses stable physical labels; missing rows are shown unresolved. Every selected row must use the same unit and report conventions in all cases. Absolute sigma comparisons also require one unit within each panel. The returned PlotDefinition works with write_presentation(..., plots=...).

layout is an optional BarLayout controlling grouping, panel arrangement, dimensions, colors and legends without changing numerical data. parameter_labels maps physical IDs to display strings (math is allowed).
