basco.covariance.observations

What is observed, when, and how precisely.

An observation type says how one observed quantity y depends on the binary. For a covariance analysis only its partial derivatives are needed:

observation_partials(gubas_state, parameters) -> (dy / d GUBAS state, dy / d parameters)

The first has shape (components, 30). The second holds only the direct dependence on the physical parameters at a fixed state (zero for most types). The design matrix combines them with the state transition matrix (see design_matrix.py). sigma is the 1-sigma noise of one observation, in the unit of y.

RelativePosition              position of the secondary relative to the primary, inertial
BodyAttitude                  orientation of one body
PrimaryBarycentricPosition    position of the primary relative to the barycentre
ScheduledObservation          one of the above, observed only at some of the epochs

ObservationSchedule holds the observation types and the epochs: every cadence seconds from one cadence after the initial time up to duration.

RelativePosition

Import as basco.covariance.RelativePosition

RelativePosition(sigma: object = 1.0, frame: str = 'inertial')

Three relative-position prediction directions, with sigma in metres. Only frame="inertial" is currently implemented.

The position of the secondary relative to the primary in inertial axes [m].

y = C_NA r, with r the relative position in the primary's frame. So dy / dr = C_NA, and dy / dC_NA[p, q] = r[q] in row p. The factor 1000 converts the stored kilometres.

sigma: 1-sigma noise of each component [m].

Import as basco.covariance.BodyAttitude

BodyAttitude(body: str, sigma: object)

Local three-component attitude prediction errors for the selected body. sigma is in radians, not degrees; use numpy.deg2rad for degree-valued uncertainty.

The orientation of one body, observed as a small rotation vector about its nominal attitude, in inertial axes [rad].

For the primary the attitude is C_NA. For the secondary it is C_NA C_AB, so a change of either matrix rotates it: theta = vee(dA A^T) + A vee(dB B^T), with A = C_NA and B = C_AB.

body: "primary" or "secondary". sigma: 1-sigma noise of each component [rad].

PrimaryBarycentricPosition

Import as basco.covariance.PrimaryBarycentricPosition

PrimaryBarycentricPosition(sigma: object = 1.0, nuisance: object = None)

Predict the primary position relative to system center of mass: -M_B/(M_A+M_B) times inertial relative separation, plus optional bias. Includes direct mass-ratio derivatives as well as transported dynamical effects. sigma is in metres.

The position of the primary relative to the binary's barycentre, inertial axes [m].

y = -M_B / (M_A + M_B) C_NA r + bias(t)

This observation depends on the masses directly, through the mass ratio, and not only through the motion. That direct part is the second array of observation_partials.

sigma: 1-sigma noise of each component [m]. nuisance: an optional PolynomialBias. With degree 1 it stands for the unknown position and velocity of the barycentre itself, which are then estimated too.

ScheduledObservation(observation_type: object, schedule: object)

Wrap one existing channel to give it its own cadence, pass windows or blackouts on the common plan grid. The wrapper preserves the channel labels, units and native partial method.

An observation type that is observed only at the epochs its own schedule selects.

ScheduledObservation(BodyAttitude("secondary", sigma), Every(2 * u.h))

gives the secondary's attitude every two hours while other types keep the cadence of the ObservationSchedule. Everything else about the wrapped type is unchanged. A schedule of the whole ObservationSchedule still applies: an epoch is observed only where both allow it.

ObservationSchedule

Import as basco.covariance.ObservationSchedule

ObservationSchedule(duration: object, cadence: object, observation_types: tuple, schedule: object = None, schedule_offset: object = 0.0)

Owns one regular base grid and channel definitions. Schedules remove selected observation rows on this grid; they do not skip propagation stages. Arbitrary off-grid observation epochs are not implemented by the fixed-step transport.

The observation types and the epochs at which they are observed.

duration, cadence: the epochs are cadence, 2 cadence, ... up to duration [s], counted from the initial time. There is no observation at the initial time. observation_types: the types observed at each of those epochs. schedule: optional (basco.covariance.schedules): selects the epochs that are observed at all, for example tracking passes or a daily blackout. schedule_offset: time [s] of this schedule's initial time on the clock that the schedules use.

The propagation always covers every epoch of the grid; a schedule only removes rows of observations. Rows are ordered epoch by epoch, and within an epoch type by type.

Your own observation type needs labels, units, sigma and observation_partials(gubas_state, parameters).
