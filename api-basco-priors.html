PriorBlock

Import as basco.PriorBlock

PriorBlock(name: str, rows: object, column_labels: tuple, column_units: tuple, row_labels: tuple, row_units: tuple, noise: object, mean: object, reference: object, source: str = 'user')

Advanced mapped prior rows with explicit layout, mean/reference and noise. Supports a prior on a derived linear combination without pretending it is a coordinate-wise independent constraint.

A prior on q with local q=q_ref+J dx, in declared physical coordinates.

mean/reference are q's physical values; rows are dq/djoint physical error. Covariance analysis uses the whitened rows. A later fitting strategy also needs the mean-reference residual; it must not discard this distinction.

GaussianPrior

Import as basco.GaussianPrior

GaussianPrior(name: str, labels: tuple, units: tuple, covariance: object, mean: object = None, source: str = 'user')

Named Gaussian knowledge on explicit coordinate labels/units and covariance. mean=None uses the producer reference convention; for iterative fitting preserve a fixed intended mean rather than recentering it at every iteration.

Gaussian knowledge of selected independent coordinates.

Labels and SI units are matched by name, never array offset. Missing mean explicitly means centered on the nominal linearization. Zero covariance does not fix a coordinate: remove it from the independent layout instead.
