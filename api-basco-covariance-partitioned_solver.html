basco.covariance.partitioned_solver

A solver that eliminates the initial state and the biases before deciding the rank.

The standard solver judges all unknowns with one relative threshold on the singular values. Over a long, chaotic arc the columns of the initial state grow by many orders of magnitude, and that one threshold then says more about those columns than about the physical parameters. This solver first eliminates the initial state and biases exactly (by QR), and applies the threshold to what remains for the physical parameters. The full covariance, with all cross terms, is still returned. A^T A is never formed.

PartitionedSquareRootSolver

Import as basco.covariance.PartitionedSquareRootSolver

PartitionedSquareRootSolver(rank_rtol: object = None, nuisance_condition_limit: float = 100000000000000.0, name: str = 'nuisance-projected Householder QR/SVD')

Alternative Householder elimination of local nuisance directions with marginal physical support diagnostics. Inspect joint versus marginal rank; its support criteria need not produce identical availability decisions to joint scaling.

Rank decided on the physical parameters after eliminating initial state and biases.

rank_rtol: relative threshold on the singular values of the parameter block; the square root of machine precision by default. nuisance_condition_limit: the largest condition number of the eliminated block that is accepted. Above it the solver raises: refine the integration or shorten the arc.

Every eliminated unknown must be determined by the observations.
