basco.validation.particle_studies.figures

Optional nominal particle figures and animations from saved data only.

The common PlotTheme and atomic output helpers own style and publication. Body context uses explicitly supplied meshes, or labelled enclosing spheres where a mesh is missing. No shape is generated or realigned by this module. Matplotlib and encoders are lazy; no dynamics are evaluated by this module. Launch points and each particle's outcome are marked; legends sit outside the data; differences use logarithmic axes so early divergence stays visible.

save_particle_figures

save_particle_figures(trajectory, destination, *, theme=None, reference=None, centre='barycenter', frame='inertial', body_meshes=None, view='system', camera=None)

Atomically save nominal PNG/SVG/PDF families and a checksum manifest.

Returns immutable metadata with absolute file paths and scientific captions. theme.formats may request a subset of the standard formats. Existing output directories are refused. frame selects inertial barycentric or simultaneous A/B body-fixed geometry; centre independently selects the inertial osculating diagnostics. body_meshes maps A/B to explicit TriangleMesh geometry in the model's body COM axes and metres. Supplied meshes are shaded at the final saved epoch; missing meshes use labelled enclosing-sphere fallbacks. No shapes are generated or realigned. Reference differences use exact saved-clock/name intersections and never interpolate. view='target' requires frame A/B and displays/bounds only that asteroid while retaining all supplied particle paths. The default shows both bodies. camera=(elevation, azimuth) uses degrees and controls only the view. The target default looks across the launch direction, keeping hops visible against open space; system keeps the standard overview camera. Overlapping physical paths may share pixels.

save_particle_animation

save_particle_animation(trajectory, path, *, frame='inertial', fps=20, max_frames=160, theme=None, body_meshes=None, view='system', camera=None)

Save GIF (Pillow) or explicitly requested MP4 (ffmpeg) using saved frames.

Frame titles show actual elapsed epochs. fps is a presentation cadence; nonuniform saved epochs are not interpolated or made physically uniform. Body-fixed histories transform each sample using that sample's body pose. Spatial axes share one fixed metre scale through the entire movie. A terminated particle keeps its observed trail and has no later point marker. Explicit body_meshes have the same body-frame SI convention as static figures. Their triangles use each frame's saved pose, including in A/B coordinates. Missing meshes have labelled enclosing-sphere fallbacks. Target view requires frame A/B and includes only that body in the geometry and bounds, while preserving every supplied particle path. camera=(elevation, azimuth) in degrees remains fixed throughout the movie; the default matches the corresponding static view. Returns immutable file/frame/geometry/caption metadata; refuses an existing path.
