basco.near_field.cylindrical

Local Fourier--Bessel potential and independent native/AD derivatives.

For dimensionless cylinder coordinates (X,Y,Z), t=X²+Y², and positive k,

phi_mn = exp(-k Z) Q_m(X,Y) 0F1(m+1; -k² t/4),

where Q_m is Re or Im of (X+iY)**m. This is the regular-at-axis normalization of exp(-k Z) J_m(k sqrt(t)) cos/sin(m phi), a separated solution of Laplace's equation. The potential is U=sum(b_mn phi_mn), in m²/s², and a=-grad(U). There is no implicit constant-density model or scientific prior on b_mn.

The decaying Fourier--Bessel form follows Fereoli et al., Celestial Mechanics and Dynamical Astronomy (2026), doi:10.1007/s10569-026-10281-7, Eq. 36; the normalization and Cartesian derivative implementations here are independent. The finite basis and patch are explicitly bounded numerical approximations, not a claim that finite exterior coefficients uniquely determine an inner field.

CylindricalBasis

Import as basco.near_field.CylindricalBasis

CylindricalBasis(patch: CylindricalPatch, azimuthal_degree: int = 2, radial_order: int = 3, radial_scale: object = None, prefix: str = 'nearfield', coefficient_scales: object = field(default=None, repr=False))

Named, axis-regular, one-sided decaying Fourier–Bessel modes in a fixed mass-free patch. Coefficients are normalized potential amplitudes in m²/s², not raw Bessel coefficients or density parameters. The zero sine mode at m=0 is excluded. Current supported numerical envelope is m≤12, radial order≤12 and full-patch Bessel argument≤4. Scales improve conditioning and supply no statistical information.

Axis-regular local cylindrical potential modes with an explicit layout.

Parameters

patch : CylindricalPatch Fixed, user-declared mass-free domain. Geometry uses body-frame metres. azimuthal_degree : int, default 2 Largest m; currently 0..12. Cosine modes include m=0, whose zero sine mode is excluded. Each m uses all radial indices 1..radial_order. radial_order : int, default 3 Number of positive J_m roots at every m; currently 1..12. radial_scale : positive float, optional Dimensionless alpha, with k_mn=j_mn/alpha and physical wavenumber k_mn/patch.radius. If omitted, max(1,max(j_mn)/4) ensures the declared full-patch |k*rho/radius| <= 4 float64 envelope. Smaller explicit scales that exceed this envelope are rejected, rather than clipped. prefix : str, default "nearfield" Coordinate namespace, e.g. "nearfield.secondary". coefficient_scales : (size,) positive array, optional Numerical coordinate scales in m²/s²; default 1. These are not sigmas or a prior. Supply uncertainty separately through the covariance layer.

Each coefficient is an amplitude in m²/s² of the normalized Cartesian mode in the module equation. This normalization differs from raw J_m amplitudes. Order is increasing m, increasing radial index, then cosine before sine. Basis identity records every mode/root, normalization and numerical policy; selecting a derivative backend does not change the physical identity.

CylindricalField

Import as basco.near_field.CylindricalField

CylindricalField(basis: CylindricalBasis, coefficients: object, backend: str = 'ad')

A local nominal potential and acceleration model. AD is default and lazy; backend='native' selects independent analytic Cartesian derivatives. The field has no built-in covariance or constant-density assumption and can be selected explicitly as a per-body particle field in RestrictedDynamics. BASCO uses a=-grad(U) with negative gravitational potential.

An uncertain-capable local potential with lazy AD or native derivatives.

Coefficients are potential amplitudes in the basis's exact coordinate order, in m²/s². The field does not assign their uncertainty: retain the full joint covariance, including trajectory/gravity cross terms, in the covariance layer. The default AD route lazily needs basco[ad] and never silently falls back. Neither construction nor a native evaluation imports JAX.
