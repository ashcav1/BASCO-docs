basco.common.contracts

What a component of your own must provide to be used in place of a built-in one.

Every part of a covariance analysis can be replaced: an observation type, a schedule, a gravity model, the source of the partials, the noise, the a priori information, the solver. Each class below lists the attributes and methods such a replacement needs. BASCO checks that they are present (isinstance(thing, ObservationType)); it cannot check that they compute the right thing, so shapes and units are checked again where the values are used.

The classes are Python "protocols": they describe an interface and are not meant to be inherited from. The built-in components are in the modules named with each one.

ObservationType

Import as basco.covariance.ObservationType

ObservationType

Prediction-direction contract: named labels/units, positive noise sigma, and signed local native-state/direct-parameter partials. Actual fixed-data residuals for nonlinear fitting are a separate contract.

An observed quantity (built-in ones: covariance/observations.py).

labels, units: one name and unit per component. sigma: its 1-sigma noise. observation_partials(gubas_state, parameters) returns two arrays: (components, 30) dy / d GUBAS state (components, p) the direct dependence dy / d parameters at a fixed state

A dependence that is zero must be returned as zeros, not left out.

GravityModel

Import as basco.covariance.GravityModel

GravityModel

Runtime-checkable minimal gravity declaration with mutual_order. Member-presence checks do not establish backend compatibility or physical correctness; maintained Hou evaluators own the Hou equations.

A model of the mutual gravity (built-in: HouGravity in binary/models.py).

mutual_order: the highest total degree of inertia integrals the model uses.

Optional: moment_solve_fors = False when single inertia integrals cannot be estimated with this model; check_model(model) to refuse unsuitable bodies; fingerprint_settings() to list the settings that identify it.

DifferentiableGravityModel

Import as basco.covariance.DifferentiableGravityModel

DifferentiableGravityModel

Optional extension capability for a JAX-traceable SI potential(r, C_AB, T_A, T_B, G). Native analytic support is not implied by supplying an AD-compatible potential.

A gravity model given by its potential energy, for automatic differentiation.

potential(r, C_AB, T_A, T_B, G) returns the mutual potential energy in joules. r [m] is the secondary's centre relative to the primary's in the frame of A, C_AB rotates components from B to A, T[l, m, n] are the inertia integrals in kg m^(l+m+n), and G is in m^3 / (kg s^2). It must be written with jax.numpy.

DynamicsPartials

Import as basco.covariance.DynamicsPartials

DynamicsPartials

Callable value-plus-derivative evaluation F, A=dF/dx and B=dF/dT used by the common variational integration owner. No specific force implementation is required by this structural protocol.

The equations of motion with partials at one GUBAS state (built-in: ADPartials, AnalyticPartials).

Called with a state, it returns (F, A, B): F (30,) the time derivative, A (30, 30) = dF / d state and B (30, i) = dF / d inertia integrals, the integrals in kg km^degree.
