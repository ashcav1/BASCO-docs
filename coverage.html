All source-level Python class/function definitions in src/basco are represented, including nested definitions and the copied legacy package. Arguments, defaults and type annotations come from the AST. Module assignments and class/constructor attributes are included; transient local variables inside a function are explained through its implementation, not advertised as configurable inputs. Runtime-generated or dependency-owned symbols are explicitly distinguished.

Public versus internal

  • Public: current exported objects and their non-private methods/properties. Use these for ordinary BASCO scripts.
  • Advanced: named module-level functions/classes for specialized work. Check the owning guide and module contract.
  • Internal: private helpers, nested definitions and implementation records. Their presence in this index is for traceability, not API stability.
  • Legacy: copied compatibility code and deprecated Cartesian multipoles. The maintained primary path is Hou AD/native.

Dataclass constructor signatures are inferred from local declarations and shown with a note; generated methods and inherited fields are not executed. External JAX/NumPy/Astropy implementations are not copied into this manual. Source docstrings are preserved, and authored notes supply units and usage where appropriate. Source links pin the exact revision.

Scientific evidence

The documented checkpoint is c00d5ff1d19c84c7e28a88507ad1f354f67f86c1. Phase 2 reproduced all 36 printed Hera Table 2 values and accepted all 160 reported sigmas, with unchanged 87 native / 117 AD bitwise snapshot items. Final ordinary suites: 240 analytic-only, 275 AD and 285 AD+plot passed. Explicit FD and scope limits are described in the derivative guide and the capability matrix.

These are recorded results from the validated checkpoint. Building documentation imports no BASCO code, propagates no trajectory, reruns no covariance and makes no new performance claim. Exact acceptance record.

Build provenance and maintenance

The build records source hashes and inventory totals in coverage.json and build-report.json. check.py verifies generated local pages, links, anchors, examples, source inventory and folder isolation. The authored files are under documentation/content/; generated pages are under documentation/site/. Rebuild after changing BASCO source. No library file or scientific dependency lock is changed by this documentation project.

Hosting and access

This website is static and works when opened locally. Local search and math assets need no network. GitHub implementation/evidence links still require repository access. The configured hosted manual is https://ashcav1.github.io/BASCO-docs/. A generated-only public mirror hosts the site; BASCO and the authoring source remain private. Publication status is recorded in the documentation project's README and STATE.

GitHub Pages has no separate hosting fee. GitHub Free supports public-repository sites; private-repository sites require an eligible existing plan. GitHub hosting rules (checked 2026-10-19). This project does not change repository visibility.
