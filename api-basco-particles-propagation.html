Error policy for nominal propagation; all dimensional tolerances are SI.

DOP853 uses componentwise tolerances and a geometric encounter step cap. RK4 uses dt as its maximum step, and must be refined explicitly. dt also bounds the initial adaptive trial. max_step is always an upper bound.

propagate_particles

Import as basco.particles.propagate_particles

propagate_particles(model, particles, *, duration, cadence=60.0, integrator=None, fields=None, backend='ad', solar=None, surfaces=None, shadow='none', start_epoch_s=0.0)

Propagate independent test particles and a coupled rotating Hou binary.

particles accepts one Particle or a sequence. Epochs are elapsed SI seconds in a common declared reference; the supplied binary/particle states already belong to start_epoch_s. Sun ephemerides use that same clock. This function never silently advances or relabels an initial model to a different epoch.

One coupled native30+6N system avoids rerunning the binary per particle. Polyhedral fields automatically supply their actual mesh contact surfaces. Other fields may be paired with supplied surfaces. Hou enclosing-sphere exits are domain_exit, not impact. Only a supplied valid near-surface field can support a launch/reimpact claim below an enclosing sphere.

Events use conservative gap/speed step limits, accepted-step inward brackets and one-sided spatial/estimated-time-tolerance termination. Tangencies and sub-tolerance hops are not a global first-root certificate. No bouncing or interpolation of a precomputed binary ephemeris is introduced.
