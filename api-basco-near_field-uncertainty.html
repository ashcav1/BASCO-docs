basco.near_field.uncertainty

Near-field coefficient covariance from original sources or declared inputs.

Original source null directions and stable consider maps remain authoritative. Finite independent coefficient errors and unresolved coefficient directions are separate inputs: neither a zero factor nor a collocation residual supplies a prior for an unknown field mode.

CoefficientUncertainty

Import as basco.near_field.CoefficientUncertainty

CoefficientUncertainty(layout: CoordinateLayout, coefficients: object, source: object = field(repr=False), jacobian: object, additional_factor: object, unresolved_scaled: object, conventions: dict, _source_latent_count: int = field(repr=False))

Construct with direct or RepresentationMap.bind. The object maps coefficient outputs through one original joint source, preserving state/mass/gravity cross terms, consider cancellation and null support. Finite added independent errors and genuinely unresolved modes are separate. No simulated observations, covariance update or new parameter fit is performed.

A coefficient vector and a Jacobian into an original joint source.

jacobian uses physical coefficient rows and full source columns. additional_factor has physical coefficient rows and explicitly independent, unit-variance latent columns. unresolved_scaled spans unknown coefficient directions after division by layout.scales. Use :meth:direct for a supplied local field, or RepresentationMap.bind for a deterministic mapping of an existing source. No new information is accumulated by either operation.

CoefficientUncertainty.direct

direct(cls, layout, coefficients, source, coefficient_jacobian=None, *, additional_factor=None, unresolved_scaled=None, conventions=None)

Accept a declared local nominal vector and full named source without an exterior model or archive. Matching coefficient labels/units select source rows by default; an explicit physical Jacobian allows other source definitions. Shared latent columns retain arbitrary state–mass–coefficient correlations. Declared finite singular distributions are valid; unknown modes must be separately marked unresolved_scaled.

Start directly with a near-field distribution, with no exterior model.

source supplies layout, map_factor and derived_stable. A SourceUncertainty.from_factor with a complete joint factor can represent correlated spacecraft, mass and local-field inputs. If no coefficient Jacobian is supplied, matching coefficient labels and units select rows from that joint source. Supply unresolved_scaled for genuinely unknown modes; a singular declared finite distribution is otherwise treated as finite, including its exact zero-variance modes.

CoefficientUncertainty.joint_report

joint_report(self, labels, values, units, source_jacobian, *, coefficient_jacobian=None, mapped_source_factor=None, conventions=None)

Without coefficient_jacobian, concatenate source-only outputs and all coefficients, retaining their cross blocks. With H=coefficient_jacobian, report coupled outputs using source_jacobian+H@jacobian before the original factor map. This retains correlated position/gravity effects and consider cancellation. An optional transported source factor must describe that complete output map; full physical Jacobians still decide support.

Concatenate source-only outputs with all local field coefficients.

With coefficient_jacobian=H, instead report coupled outputs using source_jacobian + H @ jacobian. That sum is formed before the original source map, preserving cancellation in consider coordinates. Without H, concatenate the source rows and coefficient rows, keeping their cross blocks through the original shared latent columns.

For numerically delicate pretransported source outputs, optionally pass their original mapped_source_factor; in coupled mode this must map the complete summed Jacobian. Support always comes from the complete physical Jacobian. Concatenated source-only rows have no dependence on independent added coefficient modes. Transport that couples such new modes into a spacecraft state must explicitly augment its source first.
