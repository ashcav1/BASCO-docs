basco.spacecraft.surfaces

Fixed body-frame contact surfaces, in metres, with explicit smoothness.

A closed triangle mesh supplies geometric intersections for arbitrary shapes. Its signed distance is differentiable only when the nearest point lies in one face interior. Edges and vertices remain geometric contacts, not finite smooth contact-covariance claims. No shape uncertainty is supplied implicitly.

TriangleSurface

Import as basco.spacecraft.TriangleSurface

TriangleSurface(mesh: TriangleMesh, edge_tolerance: float = 1e-07)

Contact geometry for a closed outward-wound TriangleMesh. Solid angles provide inside/outside sign; nearest-face/edge geometry provides distance and normal. A face-interior chart is required for smooth covariance. Mesh edges/vertices remain explicit geometric outcomes. Self-intersections remain the caller's shape responsibility.

Signed-distance and ray geometry of a closed, outward-wound TriangleMesh.

Closed topology is enforced by TriangleMesh. The supplied mesh must also be free of self-intersections. Signed solid angles determine containment; nearest-point distance uses face projections and all three edge segments. edge_tolerance is a dimensionless barycentric margin for declaring a differentiable face-interior event. It is not a geometric inflation.

TriangleSurface.supporting_face

supporting_face(self, direction=None, *, minimum_alignment=0.8)

Choose a real mesh face whose plane contains every vertex on or behind it. Prefer the largest centroid-centred interior disk among sufficiently aligned normals; otherwise select the most aligned support. The returned clearance is face-interior geometry, not a body-wide safe landing radius. This permits a mass-free cylinder above the supporting plane without hardcoded asteroid face indices.

Select an actual supporting face with a resolved face-interior disk.

Among faces whose outward normal meets minimum_alignment with the preferred direction, select the largest centroid-centred interior disk. If none meets that directional preference, use the most aligned actual supporting face. All mesh vertices must lie behind its plane. No convex hull replaces the supplied surface and no face index is hardcoded.
