Create a covariance run

This tutorial takes you from a new Python runner to saved figures, tables and numerical arrays. The worked example uses custom Didymos/Dimorphos inputs and the Hera observation assumptions. Each run is independent; it requires no previous results.

The same sequence applies to another binary system: define the bodies and initial state, choose the estimated quantities and observation assumptions, compute covariance, then export. Step 9 identifies the components to replace for another system.

1. Create your runner

Open a terminal in the BASCO repository folder, the one containing examples, tools, reference and src. If you have not prepared BASCO yet, complete installation first. An existing working installation needs no rebuild for changes to your own runner.

Duplicate examples/hera_custom.py as examples/my_hera_study.py. In Finder, duplicate and rename the file. The equivalent terminal command is:

cp -n examples/hera_custom.py examples/my_hera_study.py

-n preserves an existing file with that name. Your working file has this structure:

examples/my_hera_study.py
  imports and file paths
  editable physical and covariance settings
  make_model()          bodies, initial state and Hou gravity
  make_custom_study()   estimated parameters and observation assumptions
  main()               run, print and export
  bottom call to main()

The copied file already contains its imports and helper functions. Apply the edits below to that copy. Leave the installed library and reference/hera-20261016 unchanged. This template's default spin/orientation settings define a modified study, rather than an exact archived AC2 reproduction.

2. Set bodies and Dimorphos tumbling

At the top of your copy, edit these existing settings. The orientation/spin numbers below are example inputs, not a fit to a measured tumbling state:

PRIMARY_MASS_KG = hera.MASS_A_KG
SECONDARY_MASS_KG = hera.MASS_B_KG
SECONDARY_SEMI_AXES_M = (96.0, 74.0, 59.0)

SECONDARY_TO_PRIMARY_EULER_XYZ_DEG = (0.0, 3.0, 15.0)
SECONDARY_SPIN_PERIOD_H = 12.0
SECONDARY_SPIN_TILT_DEG = 30.0
Setting What you supply
PRIMARY_MASS_KG, SECONDARY_MASS_KG Nominal masses in kg. The template scales all primary mass moments consistently and recomputes secondary density.
SECONDARY_SEMI_AXES_M Dimorphos's three semi-axes in metres, not full diameters.
SECONDARY_TO_PRIMARY_EULER_XYZ_DEG Initial orientation from Dimorphos axes to Didymos axes: extrinsic x, then y, then z rotations, in degrees.
SECONDARY_SPIN_PERIOD_H Initial angular-speed magnitude expressed as a rotation period in hours.
SECONDARY_SPIN_TILT_DEG Initial angular-velocity direction from Dimorphos +z, in its body x-z plane.

Tumbling develops from the initial orientation, spin and inertia. A spin tilt is an initial condition, not an imposed constant oscillation amplitude. For a full three-component body spin, replace the spin_B construction inside make_model() with your vector in rad/s; the existing B_to_A @ spin_B converts it to the primary axes required by BinaryState.

To inspect the resulting motion before computing covariance, use the separate tumbling playground. That playground's Euler angles are relative to the orbital Hill frame; this template's angles are relative to Didymos axes. Transfer the physical attitude/state with the stated frame conversion rather than copying angle numbers between conventions.

3. Set the initial orbit

For a known state, replace these two existing settings:

POSITION_M = None
VELOCITY_M_S = None

Supply three-component vectors: secondary minus primary position in metres, and inertial relative velocity in m/s, both resolved in Didymos axes. None retains the template's archived AC2 orbit. This is the direct route for an orbit solution at a known epoch.

If you instead have semi-major axis and eccentricity, add the following block after the existing G_M3_KG_S2 = bc.G_SI line. It overrides the earlier None entries:

# Example osculating orbit at periapsis in Didymos's x-y plane.
ORBIT_A_M = 1200.0
ORBIT_E = 0.02
mu = G_M3_KG_S2 * (PRIMARY_MASS_KG + SECONDARY_MASS_KG)

# To derive a starting semi-major axis from an orbital period, uncomment:
# ORBIT_PERIOD_H = 11.4
# ORBIT_A_M = (mu * (ORBIT_PERIOD_H * 3600.0 / (2*np.pi))**2)**(1/3)

POSITION_M = (ORBIT_A_M * (1.0 - ORBIT_E), 0.0, 0.0)
VELOCITY_M_S = (
    0.0,
    np.sqrt(mu / ORBIT_A_M * (1.0 + ORBIT_E) / (1.0 - ORBIT_E)),
    0.0,
)

These are two-body Keplerian starting conditions, with 0 <= ORBIT_E < 1. The chosen plane and periapsis phase are explicit assumptions. A different orientation or phase requires the corresponding rotated position/velocity or a supplied Cartesian state. The actual period under coupled Hou gravity can differ; check the propagated orbit before interpreting a measured-period match. Spin period and orbital period describe different motions.

4. Choose the covariance settings

Edit the existing settings near the physical inputs:

GRAVITY_DEGREE = 6
ESTIMATE_DEGREES = (2, 3, 4)
PRIOR = "kaula"
DURATION_S = hera.DURATION_S
DT_S = 75.0
Setting Meaning
GRAVITY_DEGREE Nominal Hou total mutual order: 2, 4 or 6.
ESTIMATE_DEGREES Distinct uncertain moment degrees selected from 2, 3 and 4. Both masses and the physical initial state are also estimated.
PRIOR "kaula" retains the paper's shape-law/raw-moment priors; None removes them.
DURATION_S Total observation/propagation duration in seconds. hera.DURATION_S is the paper's fixed duration, not automatically 16 of your new orbital periods.
DT_S RK4 step in seconds; it must divide the 900 s observation cadence.

For a duration based on a selected reference period, explicitly set, for example, DURATION_S = 16 * ORBIT_PERIOD_H * 3600.0. The paper preset supplies observations through the last 900 s grid epoch at or before the requested duration. Choose a cadence-aligned duration when you require an exact final epoch. For a quick execution check, temporarily use DURATION_S = 3600.0; short runs do not reproduce full-arc covariance or establish observability.

The factory uses Hou AD by default. It includes relative position and Didymos barycentric position at 1 m standard deviation, both body attitudes at 1 degree standard deviation, a 900 s cadence, the free barycenter and the nuisance-projected solver. It computes measurement Jacobians and noise weights, not simulated measurement values. Observation settings and study setup explain how to replace this recipe.

Changing body shape does not refit the archived Kaula laws. Keeping PRIOR = "kaula" after a shape change deliberately retains those old laws. Supply new shape-informed priors when that is part of your study.

5. Run covariance and export everything

Replace the existing main() function with this complete function. Keep the imports, helper functions and the final if __name__ == "__main__": main() call already in your file.

def main():
    study = make_custom_study()
    print(study.describe()["unknown_labels"])
    rows = study.linearize()
    result = rows.covariance()
    print(result.summary())

    reports = {
        "mass": result.mass_properties(),
        "degree2": result.degree2(),
        "harmonics": result.harmonics(max_degree=4),
    }
    for report in reports.values():
        print(report.summary())

    folder = bc.export_study(
        rows,
        result,
        ROOT / "results",
        label="my-tumbling-g06-e04",
        reports=reports,
        figures=True,
        theme=bc.PlotTheme(tex=False, grid=True),
    )
    print(f"Results folder: {folder}")
    print(f"Figures: {folder / 'reports' / 'figures'}")
    print(f"Tables: {folder / 'reports' / 'tables'}")

linearize() performs the expensive dynamics/sensitivity propagation and constructs the design rows. covariance() solves the uncertainty problem. export_study() writes the completed data and renders figures; it does not perform another propagation. No previous-run path or comparison is required.

Run from the BASCO repository folder:

python3 -B tools/dev.py run --plot examples/my_hera_study.py

If the plotting environment has not yet been prepared, run this once before that command:

python3 -B tools/dev.py plot_environment

--plot selects the installed environment with plotting and AD available. tex=False uses built-in mathematical text, so an external LaTeX installation is not required. The launcher works outside the checkout internally; the template's ROOT uses the script location, keeping outputs under BASCO's results/.

For the saved nominal initial state, read run.json at metadata.transport_identity.initial_state_native with its native codec. Actual analysis noise is at metadata.diagnostics.noise. Keep your editable runner as the readable record of the settings you supplied; configuration.json is a study description rather than a copy of that script.

relative_sigma in CSV tables is a fraction; multiply by 100 for percent. A zero nominal coefficient has no defined relative error, even when its absolute sigma is meaningful. Read each row's status: fixed, supported and unresolved quantities have different meanings.

The information spectrum is a numerical support diagnostic in declared scaled coordinates. result.summary() reports data and posterior rank separately; priors can support a posterior without making that direction observable from the observations. A tiny or unavailable sigma is not, by itself, evidence of observability. Results and exports describes nullspaces, correlations and supported reports.

The export's validation/README.md does not certify a run. Finite-difference validation is a separate opt-in operation.

7. Read saved numerical data in Python

Create a separate file examples/read_my_run.py. Paste the following script and replace the folder-name placeholder with the complete name printed by your run, including timestamp and digest:

from pathlib import Path
import basco as bc

ROOT = Path(__file__).resolve().parents[1]
RUN = ROOT / "results" / "PASTE-YOUR-COMPLETE-RUN-FOLDER-NAME"

arrays, presentation, run = bc.read_run(RUN)
print(presentation.summary)
print("Available arrays:", sorted(arrays))
print("Observation matrix shape:", arrays["design_rows_SI"].shape)

labels = run["metadata"]["layouts"]["joint_coordinate"]["labels"]
print("Joint coordinate order:", labels)
if "joint_covariance" in arrays:
    P = arrays["joint_covariance"]
    print("Joint covariance shape:", P.shape)
else:
    print("No finite full joint covariance; inspect reported null directions.")

Run it with:

python3 -B tools/dev.py run examples/read_my_run.py

This verifies saved-file checksums and loads data. It does not propagate dynamics or solve covariance again. Use names from the saved metadata rather than guessing a mass or gravity column number.

Saved array Meaning
epochs_s Saved transport epochs in seconds.
design_rows_SI Observation Jacobian; columns follow the joint coordinate labels.
joint_covariance Full physical joint covariance, present only when the joint solution is supported.
supported_subspace_covariance, nullspace_scaled Supported/null information; the first is not a finite covariance for arbitrary unresolved coordinates.
state_transition, parameter_sensitivities Saved state/parameter transport arrays. Read their separate axes and units in run.json.
native_states Original native30 states. Position/velocity use km and km/s in this internal codec; do not read them as SI metres.

8. Regenerate figures without another run

To change figure size, grid or typography, append this to read_my_run.py:

FIGURES = RUN.with_name(RUN.name + "-restyled")
bc.write_presentation(
    presentation,
    FIGURES,
    figures=True,
    theme=bc.PlotTheme(tex=False, grid=True, width=10.0, font_size=11.0),
)
print("Restyled figures:", FIGURES / "figures")

Run the reader using the plotting environment:

python3 -B tools/dev.py run --plot examples/read_my_run.py

The new presentation is a sibling of the original run, with its own figures/, tables/ and report files. It requires a new destination name if one already exists. This preserves the original run and its checksums. No new dynamics or covariance calculation occurs.

9. Use another binary or observation model

Keep main() and the export/loading workflow. Replace the physical model and study composition through their existing components:

What changes Where to edit Component reference
Another primary shape or mass distribution primary construction in make_model(); the supplied template otherwise retains Didymos's normalized shape Bodies, moments and frames, shape-model moments
Another secondary shape or density model secondary construction in make_model() Body, MomentDistribution
Initial orbit and both bodies' rotations BinaryState assembled in make_model() State fields
Which masses/moments/coefficients are uncertain The parameter map used in make_custom_study() Parameter selection
Observed quantities, noise and cadence Supply your own ObservationPlan to a CovarianceStudy instead of using the Hera recipe Study setup, observations
Prior information Supply your own prior producers; do not assume the Hera shape laws apply to another body Noise and priors

The current make_custom_study() calls the installed Hera factory. When you need a different experiment, construct CovarianceStudy directly with your model, parameters and plan as shown in study setup. The complete generic example shows that composition without Hera reference inputs. The solve, reporting and file-reading steps on this page remain the same.
