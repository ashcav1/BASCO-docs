basco.state

The preserved native30 storage layout and physical SI corrections to it.

Native30 (the retained C++ codec): r [0:3] in km and v [3:6] in km/s, both the secondary relative to the primary and resolved in A; omega_A [6:9] and omega_B [9:12] in rad/s, resolved in A; C_NA [12:21] and C_AB [21:30] stored row-major. These names are the single owner of that layout.

retract_native

Import as basco.retract_native

retract_native(native_state, physical_error)

Apply a finite physical SI/local-SO(3) error to a native30 state. This is an explicit estimation/retraction utility rather than a propagation-time correction.

Return native30 after an independent physical18 correction.

Position and velocity errors are in metres and metres/second. Spin errors are added in the stored A components, in radians/second. The last six entries are left rotation vectors: theta_A in N and theta_B in A. Both DCMs use row-major storage. Existing nominal DCM drift is preserved; this function never projects, normalizes, or changes the nominal state.
