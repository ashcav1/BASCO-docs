raw_moment_check

Import as basco.validation.raw_moment_check

raw_moment_check(model, parameters, *, steps=None, provenance=None)

Prepare the complete resolved independent-to-raw SI map check.

Preparation launches no probes. The forward path uses only raw_values; the separate stored analytic Jacobian is defined at the resolved nominal. Every raw output has a positive mass*length**degree characteristic scale, including fixed or selected zero-nominal moments.

physical_state_check

Import as basco.validation.physical_state_check

physical_state_check(model, *, steps=None, provenance=None)

Check native30/physical18 lift against independent left SO(3) values.

The point is zero physical error about the fixed initial native state. Position/velocity use SI inputs and native km outputs; all finite rotations are evaluated by retract_native without consulting a manual derivative.
