basco.covariance.priors

A priori information: what is known about the unknowns before the observations.

A priori information enters least squares as extra rows. Knowing a quantity q = J x with covariance P0 = L L^T is the same as having observed it with that noise, so the whitened rows L^-1 J are stacked under the whitened design matrix. Without a priori information for an unknown, that unknown is determined by the observations alone.

APrioriCovariance     a covariance for some of the unknowns, chosen by name
APrioriInformation    the general form: rows J and a noise model
KaulaPrior            a Kaula rule for the gravity coefficients (kaula.py)

APrioriInformation

Import as basco.covariance.APrioriInformation

APrioriInformation(name: str, rows: object, column_labels: tuple, column_units: tuple, row_labels: tuple, row_units: tuple, noise: object, mean: object, reference: object, source: str = 'user')

Advanced mapped prior rows with explicit layout, mean/reference and noise. Supports a prior on a derived linear combination without pretending it is a coordinate-wise independent constraint.

A priori information in its general form: q = J x is known with some covariance.

name: identifies this information; the same name cannot be used twice. rows: J, with one column per unknown of the analysis. column_labels, column_units: the unknowns the columns refer to. row_labels, row_units: the quantities q. noise: the covariance of q (sigmas, a matrix or a noise object). mean: the a priori value of q. reference: the value of q at the nominal unknowns. source: where the information comes from, for the records.

A covariance analysis uses only the whitened rows. mean and reference matter when parameters are actually fitted: their difference is the a priori residual.

APrioriCovariance

Import as basco.covariance.APrioriCovariance

APrioriCovariance(name: str, labels: tuple, units: tuple, covariance: object, mean: object = None, source: str = 'user')

Named Gaussian knowledge on explicit coordinate labels/units and covariance. mean=None uses the producer reference convention; for iterative fitting preserve a fixed intended mean rather than recentering it at every iteration.

An a priori covariance for some of the unknowns.

APrioriCovariance("masses", ("primary.mass", "secondary.mass"), ("kg", "kg"), P0)

name: identifies this information. labels, units: the unknowns it applies to, by name, with their units. covariance: their covariance matrix (positive definite). mean: their a priori values; the nominal values when not given.

A zero variance is not accepted as a way to fix an unknown; leave it out of the estimated parameters instead.
