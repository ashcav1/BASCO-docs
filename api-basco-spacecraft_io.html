basco.spacecraft_io

Restore completed covariance factors and binary transport without new analysis.

This adapter reads the existing checksummed run format. It never constructs observations, regenerates linearization rows, fits parameters or factors a stored covariance. Original source coordinates, latent error factors and conditional consider cancellation remain unchanged.

RetainedCovarianceSource

RetainedCovarianceSource(uncertainty: SourceUncertainty, transport: Transport, analysis_identity: str, information_cutoff_s: float, metadata: object)

Verified source uncertainty and its original binary transport. The original observation-row epochs determine the included-information cutoff; a configured duration is not substituted. This adapter restores persisted capabilities, without recreating diagnostics or priors that were not exported.

Verified original uncertainty and nominal/variational binary history.

transport retains elapsed epochs relative to its original zero. The source coordinate epoch is uncertainty.reference_epoch_s; the absolute information cutoff includes that origin. analysis_identity identifies the original solve, not a new estimation. Metadata records the persisted capabilities; diagnostics absent from the export are not reconstructed.

load_covariance_source

load_covariance_source(source, parameters, *, reference_epoch_s=0.0)

Reload a completed standard run with its original factor and compatible nominal/variational binary transport. Parameter labels/order/units, nominal/raw physical map, source identity and persisted array contracts are verified. Consider sources retain conditional factors, response and external factor for cancellation-aware maps. No observation values, new rows, refit or dense-covariance factor reconstruction occur. Source exports must retain their original factors.

Load a completed BASCO covariance run with its original factor/transport.

parameters is the identical resolved physical map or its builder; model, parameter labels/order/units, nominal values, raw Jacobian and numerical transport identity must agree. No observations or solver are called. Runs exported without include_factor=True fail explicitly.

reference_epoch_s assigns the absolute elapsed-second origin to the original source coordinates. The information cutoff is that origin plus the largest saved observation-row epoch, never the configured duration. Forecast callers must release at or after that cutoff. Original binary transport epochs remain relative to zero for retained transport contracts.
