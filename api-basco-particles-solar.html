basco.particles.solar

Nominal solar tides, leading gravity-gradient torques, and cannonball SRP.

All translations are SI in nonrotating binary-barycentric axes. The Sun's position must be supplied in those same axes relative to the moving binary barycentre, on the propagation's declared epoch clock. This module does not integrate a heliocentric barycentre or transform time scales/reference frames.

Formula provenance (primary sources retrieved 2026-11-09):

  • IERS Technical Note 21, chapter 10, p. 81: inverse-square cannonball SRP, pressure 4.560e-6 N/m² at 1 au, area/mass and multiplicative C_R: https://www.iers.org/SharedDocs/Publikationen/EN/IERS/Publications/tn/TechnNote21/tn21_81.pdf
  • NASA report 19860005869, gravity-gradient torque Eq. (27): 3 mu/R³ (s_hat x I s_hat), resolved in the body's own axes: https://ntrs.nasa.gov/api/citations/19860005869/downloads/19860005869.pdf
  • JPL Solar System Dynamics, Astrodynamic Parameters: DE440 solar GM and the IAU 2012 exact astronomical unit: https://ssd.jpl.nasa.gov/astro_par.html

Only nominal values are provided. No AD or covariance derivative capability is implied. Binary translation uses point-centre solar forces; each body's torque uses only its leading quadrupole. Neither finite-body solar force corrections nor radiation pressure on the binary are modeled.

TabulatedSun

Import as basco.particles.TabulatedSun

TabulatedSun(epochs_s: object, positions_m: object, _: KW_ONLY, frame: str = _FRAME, epoch_convention: str = _EPOCH, interpolation: str = 'linear')

Piecewise-linear barycentre-to-Sun positions with closed time bounds.

Epochs are at least two strictly increasing finite SI seconds. Positions have shape (n_epochs, 3) in metres. Both endpoints are accepted; any request outside them raises ValueError, including integrator stages outside support. frame and epoch_convention are identity labels, never transforms. Interpolation is explicitly linear; no spline, extrapolation or provider fallback is performed. Table resolution and ephemeris accuracy are the caller's responsibility.

SolarForces

Import as basco.particles.SolarForces

SolarForces(sun: object, _: KW_ONLY, mu_sun: float = MU_SUN, gravity: bool = True, srp: bool = True, perturb_binary: bool = True, binary_torques: bool = True, pressure_1au: float = PRESSURE_1AU, au_m: float = AU_M)

Compose independently selected nominal solar effects.

gravity enables particle solar gravity minus the mass-weighted binary origin acceleration. That subtraction ALWAYS applies when gravity is on. perturb_binary additionally enables a_B-a_A in the binary relative equation when gravity is on; disabling it freezes the binary relative solar perturbation, while its origin still follows the mass-weighted Sun force. binary_torques independently enables the leading gravity-gradient torques, even when translational gravity or perturb_binary is disabled. srp enables particle-only cannonball radiation pressure away from the Sun. There is no binary SRP force or radiation torque.

A/m is projected Sun-normal area divided by mass [m²/kg]. reflectivity is the nonnegative multiplicative C_R (not the excess reflectivity C_R-1). Each may be a scalar or one value per particle. illumination is an externally calculated factor in [0,1], applied ONLY to SRP; None means full illumination. This module provides no shadow geometry.
