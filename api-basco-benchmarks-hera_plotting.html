basco.benchmarks.hera_plotting

Hera paper layouts composed from the generic presentation interface.

No propagation, prior construction or covariance calculation occurs here. The supplied PresentationDataset rows remain the only numerical source. Typography and palette are defined by PlotTheme; BarLayout owns geometry.
