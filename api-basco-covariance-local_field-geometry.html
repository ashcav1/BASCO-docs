basco.covariance.local_field.geometry

The cylinder in which a local gravity field is used.

The cylinder is assumed to contain no mass, so that the potential satisfies Laplace's equation inside it. That is the user's assumption: this code does not check the cylinder against the body's shape.

CylindricalDomain

Import as basco.covariance.local_field.CylindricalDomain

CylindricalDomain(origin: object, radius: object, height: object, rotation: object = field(default_factory=lambda: np.eye(3)))

Fixed body-frame cylinder with a base origin and local positive-z axis. Geometry uses SI metres and a proper cylinder-to-body rotation. Its boundary is included with a documented roundoff tolerance. The caller must establish that the domain is mass-free; constructing a patch does not check a shape mesh or include uncertain patch pose.

A cylinder fixed in a body's frame.

origin: (3,) centre of its base [m], in the body's frame. radius, height: [m]. rotation: (3, 3) matrix whose columns are the cylinder's x, y and z axes in the body's frame; z is the cylinder's axis, pointing from the base to the top.
