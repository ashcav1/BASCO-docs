# BASCO documentation

Read the manual: https://ashcav1.github.io/BASCO-docs/

This public repository contains only the generated BASCO documentation website and PDF handbook. The BASCO library, authoring tools, source inventory and scientific data remain in the private source repository. Implementation links in the manual require access to that repository.

Derived figures, videos and self-contained flight viewers are published with the manual. Viewers embed display geometry, position regions and probe outcomes, not original source factors or scientific run artifacts.

The static website also works locally: open index.html in a browser.
