basco._legacy.f2bptoolkit.montecarlo

Legacy compatibility reference. Prefer current BASCO workflows; copied implementation details are not new development targets.

Monte Carlo consistency test of the formal covariance.

The covariance machinery in :mod:cases never solves for anything: it linearises the measurements about the truth and reports what a linear estimator WOULD achieve. This module closes the loop the way the estimation literature expects (Bar-Shalom's consistency test; the check Scheeres's review called "the single most valuable missing check in the project"):

  1. take the truth trajectory of a configured system,
  2. manufacture noisy synthetic measurements from it, many times over,
  3. run an actual batch least-squares estimator on each set -- iterating the NONLINEAR model (re-propagating from the corrected initial state and the corrected inertia integrals) against the measurements,
  4. compare the scatter of the estimates to the formal covariance: per-parameter sample-sigma / formal-sigma ratios (should be 1) and the normalised estimation error squared, NEES = e' P^-1 e, whose average over N samples must sit inside the chi-square band for the number of estimated parameters.

The Jacobian is held at the truth (a "fixed-Jacobian" Gauss-Newton). It is therefore the same H that run_case linearises with -- taken straight from run_case(return_channels=True) so no derivative code is duplicated -- and the test isolates exactly what the linear analysis assumes: that the residual r(x) is linear in the estimated quantities over the range the noise excites. Predictions come from the full nonlinear propagation every iteration.

Estimated quantities: the 18 physical initial-state degrees of freedom (in the same tangent basis as run_case) and the case's parameters as FRACTIONAL deviations from truth (the same truth-scaled columns run_case uses).

add_prior

add_prior(bp: BatchProblem, prior_sigma) -> BatchProblem

Return a copy of the problem with a FRACTIONAL a priori on every estimated parameter (Lambda_0 of the classical formulation), appended to the whitened design as rows [0_18 | diag(1/sigma_prior)], and the formal covariance recomputed from the augmented design (state marginalised).

Why it is needed for a Monte Carlo: without it the primary's trace direction is nearly flat over the noise-induced range (30-50 % formal sigma at 16 orbits, several hundred % at 4), and the batch estimator's answer along it depends on where the iteration starts. A weak prior makes the nonlinear problem well posed, exactly as a real orbit-determination analysis would (Scheeres's review item 6); the same prior enters the formal covariance, so the comparison stays like for like.

solve_sample

solve_sample(bp: BatchProblem, seed: int, max_iter: int=10, tol: float=0.0001, fd_step: float=0.0001, x0_start=None, integrals_start=None, record_iterations: bool=False, relinearise_state: bool=True, state_fd_step: float=1e-06, start_at_prior: bool=False)

Batch least squares on one synthetic data set.

Gauss-Newton with the FULL Jacobian re-evaluated about the current estimate every iteration by central finite differences of the whitened residual: the parameter columns at fd_step (fractional) and, unless relinearise_state=False, the 18 state columns at state_fd_step of the group scale. Both are needed: the weakly determined moments move by tens of per cent, where the model is visibly nonlinear, and the state columns change with them (the primary's trace direction is a state-parameter cancellation, so a state Jacobian held at the truth mis-directs the iteration once the parameters have moved). Steps are backtracked (halved, up to five times) if they do not lower the whitened residual sum of squares. Stops when the largest fractional parameter step is below tol and the scaled state step below 1e-6, or at max_iter.

Returns the final fractional parameter errors, the state errors (km, km/s, rad/s, rad), the linear-limit errors from the same noise, the per-sample formal sigmas at the solution (from the re-linearised Jacobian), the iteration/propagation counts and the post-fit residual RMS.
