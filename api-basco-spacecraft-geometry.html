basco.spacecraft.geometry

Binary barycentric body poses and their exact stored-coordinate derivatives.

No attitude projection is performed. Rotations retain the same ambient DCM representation as the Hou binary integrator; derivatives apply to those coded matrix products, including the small off-manifold RK4 drift.

BodyPose

Import as basco.spacecraft.BodyPose

BodyPose(position: object, velocity: object, rotation: object, omega: object)

One asteroid's barycentric position/velocity, body-to-N rotation and spin.

position [m], velocity [m/s], rotation [dimensionless 3x3] and omega [rad/s, resolved in N] are readonly. These are nominal kinematics, not a source covariance or independently interpolated binary ephemeris.

body_poses

Import as basco.spacecraft.body_poses

body_poses(native_state, mass_A, mass_B)

Return primary/secondary BodyPose objects in inertial barycentric SI.

Native v_A is inertial relative velocity expressed in A; it is not dr_A/dt. Thus v_relative_N = C_NA v_A * 1000, with no extra spin term. Both body COM positions depend on the mass ratio.

body_pose_jacobians

body_pose_jacobians(native_state, mass_A, mass_B)

Differentiate body COM positions/rotations without assuming C.T C = I.

The two COM fractions have identical mass derivatives. A mass-ratio perturbation translates both centers at fixed relative binary state; their separation is unchanged. Spin/velocity affect future poses through the binary STM, while this instantaneous position/rotation map is zero in those local columns.
