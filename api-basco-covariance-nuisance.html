basco.covariance.nuisance

Biases of an observation that are estimated along with the physical parameters.

A bias is not a property of the binary. It belongs to an observation type (for example the unknown offset and drift of the barycentre in PrimaryBarycentricPosition), but it is an unknown of the same least-squares problem, so it gets columns in the design matrix.

PolynomialBias

Import as basco.covariance.PolynomialBias

PolynomialBias(name: str, degree: int = 1, components: tuple = ('x', 'y', 'z'), unit: str = 'm', reference_epoch: object = 0.0, scales: object = None, nominal: object = None)

Observation-only polynomial coordinates with explicit units/reference epoch. Degree 1 and three components add barycenter position and rate; no prior is introduced implicitly. These are nuisance parameters, not a change to nominal binary gravity.

A bias that is a polynomial in time, for each component of an observation:

bias(t) = c_0 + c_1 (t - t0) + c_2 (t - t0)^2 / 2

name: used in the labels, as in "barycenter.offset.x" and "barycenter.rate.x". degree: 0 (offset), 1 (offset and rate) or 2 (and acceleration). components: the components that have a bias. unit: the unit of the offset. reference_epoch: t0 [s]. scales: typical sizes of the coefficients (not a priori information). nominal: their nominal values, zero by default.

The coefficients are free unless an a priori covariance is given for them.
