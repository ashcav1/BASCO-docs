basco.covariance.trajectory.epoch_mapping

Starting a particle at a later time than the one the covariance refers to.

The covariance of the binary refers to its initial time t0. A particle that starts at a later time t1 starts from the binary's state at t1, and that state depends on the uncertain inputs q at t0 through the state transition matrix and the parameter sensitivities of the binary. BinaryEpochMapping holds the state at t1 with that dependence, and ParticleInitialState combines it with the particle's own initial state into

J0 = d (binary and particle state at t1) / d q

which the variational equations then carry forward.

BinaryEpochMapping(gubas_state: object, source_jacobian: object, parameters: object, reference_epoch_s: float, epoch_s: float, fingerprint: PropagationFingerprint, metadata: dict)

An exact stored binary epoch and its linear map from original physical initial-state/parameter errors. Construct through from_variational_solution so transport identity, SI raw map and nominal model are verified. Source and release epochs remain distinct; the original DCMs are retained.

ParticleInitialState

Import as basco.covariance.trajectory.ParticleInitialState

ParticleInitialState(parameters: object, state: object, layout: ParameterLayout, initial_jacobian: object, inertia_integral_parameter_jacobian: object, reference_epoch_s: float, release_epoch_s: float, metadata: dict)

Combined release state and named original-source Jacobian J0. The raw map uses mass-weighted SI moments. Downstream transport composes Phi J0 + Psi raw_map once, preserving the original source layout and cross covariance. Ordinary callers pass initial and handoff to RF3BPDynamics.propagate; inspect trajectory.initialization for the resulting map.

The 36-number state at the start of a particle propagation, with its partials.

state: GUBAS state of the binary and inertial state of the particle. layout: the uncertain inputs q it depends on. initial_jacobian: J0 = d state / d q. inertia_integral_parameter_jacobian: d T / d q, for the parameter sensitivities. reference_epoch_s, release_epoch_s: the time q refers to and the starting time.
