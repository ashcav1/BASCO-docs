write_presentation

Import as basco.write_presentation

write_presentation(dataset, destination, *, figures=False, theme=None, plots=None)

Atomically write JSON, Markdown, CSV and LaTeX tables, plus optional PNG/SVG/PDF figures, from a presentation dataset. The destination must be new; existing completed results are not overwritten.

Publish a new directory atomically; plot failure leaves no completed report.

ArgumentType / defaultMeaning

None		Optional PlotTheme; tex=True needs an external TeX install.
